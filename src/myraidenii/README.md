# MyRaidenII Source

This is the owner-selected product root, without an app- prefix. Its three
active components are `core` (the selected deterministic board), `machine`
(the one Emulator driver and external-image transaction), and `product`
(configuration, identity and composition). See the
[architecture](../../docs/myraidenii/design/ARCHITECTURE.md) and
[source map](../../docs/myraidenii/design/CODING.md) before changing a
component boundary. The active M1 qualification task has not established
gameplay or release readiness. Do not place game ROMs, reference code or
generated embedding here.
