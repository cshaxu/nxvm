# T435 S1 - 80186 Manual and Model Ledger

## Status and boundary

This is block 2 of T435 S1.  It covers every 80186 successful-retirement
instruction form and context: the inherited 8086 set, the 80186 additions, all
legal prefixes and repetitions, and all branch outcomes.  It does not change
runtime code or begin the 80286 block.

## Timing interpretation

Table 1-16's `n(m)` notation means `n` clocks for an 8086 and the parenthetical
`m` clocks for the same 80186 instruction.  In the rows whose 8086 notation has
`+EA`, the 80186 parenthetical value is its own table value: it is not combined
with Table 1-15's 8086 EA formula.  For an odd-addressed 16-bit operand
transfer, the manual adds four clocks; segment override and repeat are used
only where their own Table 1-16 form/formula says so.  The table assumes that
the instruction is already prefetched and has no external wait.  Prefetch,
READY, HOLD, bus competition, and integrated-device service remain outside this
successful-retirement program.

For a manual range with no manual formula, midpoint is
`ceil((low + high)/2)`.  It is labelled L2, not L3.

## Non-instruction events

`INTR`, `NMI`, and single-step appear in Table 1-16 only as event timing
information; they are not successful instruction retirement.  Divide error,
BOUND failure, invalid opcode, and ESC extension traps are likewise separate
exception-delivery rows.  The 80186's integrated DMA, timers, interrupt
controller, chip selects, and ports are separate device/transaction work and
must not be charged to an instruction scalar.

## Coverage result

Every 80186 successful-retirement form has an Intel Table 1-16 classification.
There are no principle-only or no-timing instruction rows and no proposed L1
row.  Exact/formula forms are L3.  Only documented ranges are L2 fixed
midpoints because no conforming dynamic 80186 reference model was found; those
midpoints are explicit, reviewable, and never an anonymous one-tick fallback.

Before runtime implementation, this grouped ledger must be mechanically mapped
to concrete decoder form/context keys.  The evidence/model decision itself is
complete; owner review is required before starting 80286.
