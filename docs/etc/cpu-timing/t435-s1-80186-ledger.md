# T435 S1 - 80186 Manual and Model Ledger

## Status and boundary

This is block 2 of T435 S1.  It covers every 80186 successful-retirement
instruction form and context: the inherited 8086 set, the 80186 additions, all
legal prefixes and repetitions, and all branch outcomes.  It does not change
runtime code or begin the 80286 block.

## FLAGS image and restore contract (T499 S12)

The local primary archive contains I186-UM-1985 (210912-001): its FLAGS
storage-format material identifies the defined low FLAGS fields, but does not
give an exact architectural `PUSHF`/`POPF` value for reserved bits. The
80186/80188 does not acquire the later IOPL/NT fields, so Core canonicalizes
bits 12--15 to deterministic zero at the same profile-owned boundary as
8086/8088. The profile test asserts only the documented `0FD5h` fields and
does not assert a reserved image value. This is a stated L2 evidence boundary,
not an L3 claim.

## Timing interpretation

Table 2-9 is the primary 80186 result: it names the concrete encoded forms,
marks the 80186-only rows, and states the 80186 execution-time assumptions. Its
memory-form values include its stated four-clock EA calculation where applicable.
Table 1-16 is a corroborating 8086/88 chapter table: its parenthetical 80186
column, repeat detail, prefix cost and odd-word footnote are consulted only when
they do not contradict the 80186-specific Table 2-9 result.  The two tables do
disagree for a finite set; the decision record below preserves each conflict.
No 8086 `+EA` term may be added to a Table 2-9 value.  Prefetch, READY, HOLD,
bus competition, and integrated-device service remain outside this
successful-retirement program.

For a manual range with no manual formula, midpoint is
`ceil((low + high)/2)`.  It is labelled L2, not L3.

## Re-audit source-conflict decisions

The prior ledger mixed the 8086/88 chapter's parenthetical column with the
80186-specific instruction summary.  The following differences were found by
reading both in the authorized 1985 manual.  Table 2-9 wins because it is the
80186/80188 CPU chapter's complete encoded-form summary and explicitly defines
its timing assumptions.  Table 1-16 remains the source for repeat/prefix and
odd-word details absent from Table 2-9; it cannot override an incompatible
Table 2-9 scalar.

| form(s) | Table 1-16 parenthetical | Table 2-9 primary result | disposition |
| --- | --- | --- | --- |
| `MOVS`, `LODS` primitive | 9; 10 | 14; 12 | Table 2-9 L3 exact |
| `PUSH imm16`, `PUSH imm8` | 14; 14 | 10; 10 | Table 2-9 L3 exact |
| direct near `CALL`; direct `JMP` | 14; 13 | 15; 14 | Table 2-9 L3 exact |
| immediate `IMUL` | 22--24; 29--32 | 22--25; 29--32 | Table 2-9 L2 midpoints 24; 31 |
| `BOUND` | 35 | 33--35 | Table 2-9 L2 midpoint 34 |
| `LAHF` | 2 | 2 | no conflict; prior ledger's 4 was an entry-order transcription error, corrected to 2 |

This table is a decision record, not a claim that the manual is internally
uniform.  Later implementation must cite the selected Table 2-9 row and may
add only the separately-authorized repeat/prefix/odd-transfer terms.

## Non-instruction events

`INTR`, `NMI`, and single-step appear in Table 1-16 only as event timing
information; they are not successful instruction retirement.  Divide error,
BOUND failure, invalid opcode, and ESC extension traps are likewise separate
exception-delivery rows.  The 80186's integrated DMA, timers, interrupt
controller, chip selects, and ports are separate device/transaction work and
must not be charged to an instruction scalar.

## Coverage result

Every 80186 successful-retirement form has an Intel Table 2-9 primary
classification or a documented Table 1-16 supplemental formula.  There are no
principle-only or no-timing instruction rows and no proposed L1 row.
Exact/formula forms are L3.  Only documented ranges are L2 fixed midpoints
because no conforming dynamic 80186 reference model was found; those midpoints
are explicit, reviewable, and never an anonymous one-tick fallback.

Before runtime implementation, this grouped ledger must be mechanically mapped
to concrete decoder form/context keys.  The evidence/model decision itself is
complete; owner review is required before starting 80286.
