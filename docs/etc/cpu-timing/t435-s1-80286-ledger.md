# T435 S1 - 80286 Manual and Model Ledger

## Status and boundary

This is block 3 of T435 S1. It covers every 80286 successful-retirement
instruction form and context: compatible 8086/80186 forms, 80286 additions,
real/protected-mode alternatives, legal prefixes/repetitions, and each
successful branch or privilege path. It does not change runtime code or begin
the 80386 block.

## Timing interpretation and ownership boundary

`Clocks` in Appendix B is the authoritative internal instruction result. `mem`
selects the memory operand row; `noj` selects a not-taken conditional path; and
`pm` selects protected mode. Add one clock for base+index+displacement EA, two
clocks for each odd-addressed 16-bit memory operand reference, and one per
memory-read wait state. A number of control transfers add one clock for each
byte of the next instruction executed. Repeats and shifts/rotates provide their
own explicit formulae.

Thus the first three adjustments and next-instruction-byte formula are L3 CPU
timing inputs, while READY wait states, BUSLOCK/HOLD arbitration, port/device
service, BUSY duration, prefetch starvation, and the manual's stated average
5--10 percent fetch-pressure observation are external transaction/device
effects. They must not be silently added to a successful-retirement scalar.
`WAIT` has a three-clock successful completion row; time while BUSY remains
active is an external wait, not an invented per-instruction duration.

No L2 substitution is needed: Intel supplies an exact value, labelled context,
or an explicit formula for every successful 80286 instruction form. No
principle-only or no-timing instruction form remains, and no L1 one-tick
fallback is permitted.

## Coverage result

The manual has enough detail to implement a hand-book-correct L3 80286 timing
program, including its internal contextual inputs. Implementation must preserve
the boundary above and mechanically map every grouped manual form/path to a
decoder key; it may not replace unimplemented form coverage with the existing
generic fallback. This evidence decision is complete. Owner review is required
before S1 block 4 (80386) begins.
