## Previous Debt

The [complete former debt snapshot](debt-snapshot.md) preserves every original
entry. Its unchecked boxes and historical statements are not current status.

- **External integration restoration:** later layout closure records 42/42.
  Preserve old failure evidence; the fixed-product task rebaselines every row
  before retirement. Do not portray old 39/42 or 41/42 as today's result.
- **Model-40/5170 boot chain, Compaq disk/CECG/diskette/firmware/physical timing,
  IBM MFM residual:** old product obligations withdrawn. The fixed-product
  audit must first retain any CPU/shared-device mechanisms and regression
  value; this is scope retirement, not a claim those historical gaps were fixed.
- **XT/AT PIC wiring, digital CGA/EGA/VGA, board speaker/PPI, serial/parallel:**
  transfer required selected-board behavior to controller qualification.
  Unselected optional breadth stays in current peripheral debt.
- **ELCR/PCI/APIC, advanced AUX, composite/light-pen effects:** unplanned unless
  an approved target actually requires them; current peripheral debt remains.
- **Large/sparse native media:** the later file-backed Lib route is already
  the sole owner. Remove the obsolete resident-image prescription. Browser
  backing remains separate unplanned debt.
- **CPU reset/shutdown/triple fault, real-mode corpus, 286/386 protected-mode,
  system extensions, arithmetic formula evidence and holistic execution audit:**
  transfer to retained-CPU qualification. The CPU exception preserves these
  obligations regardless of machine retirement.
- **Descriptor vocabulary, debug CR mutation, x87, VME/PVI, fault reporting,
  assembler checkop:** remain explicitly in current unplanned debt.
- **Default generated-ROM materialization:** obsolete future design withdrawn;
  fixed-product construction requires real supplied ROMs, not a new generated
  BIOS path. Existing bytes/paths are audited before deletion.
- **Bounded Bochs comparison:** transfer to differential/test proposal.
- **Profile physical timebase:** transfer to the selected-controller/board
  ledger with Core CPU prerequisites; obsolete named-board completion is not
  promised. Unsupported analog/physical behavior remains explicit debt.
- **Console speed-help accuracy:** inspect against the retained pacing route
  during fixed-product App/config cutover; no third mode or tick source.
- **Strict compilation, Linux runtime, DevBox:** remain in current debt.

No entry is silently accepted as repaired. CPU/chip evidence survives even
when its former board or queue package is withdrawn.
