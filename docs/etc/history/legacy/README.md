# Historical Summaries

History is compact by design. It preserves milestone-level outcomes while Git
retains the completed task plans, tracking records, verification logs, and
move-by-move provenance removed by M5 T208.

- [M0--M4 summary](m0-m4.md)
- [M5 summary](m5.md)

For a retired detailed record, inspect its last revision with `git log --all
-- docs/<former-path>` and `git show <commit>:docs/<former-path>`. Historical
material cannot redefine current architecture, requirements, roadmap, or
closure status.
