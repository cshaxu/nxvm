# Supporting Documentation Index

This owner-approved area preserves supporting material that does not define a
current rule, architecture, requirement, status, queue, or debt decision. M5
Td S46 approved the following bounded categories:

| Area | Purpose | Owner / retirement condition |
| --- | --- | --- |
| `architecture-notes/` | Detailed completed migration and design evidence. | Architecture owner; merge into a current design authority only when still normative. |
| `baselines/`, `fixtures/`, `build/`, `templates/` | Reproducible baseline, fixture, toolchain, and evidence support. | Execution owner; retire when the referenced baseline is replaced. |
| `governance/` | Supplemental source, asset, evidence, and milestone-closure material. | Relevant rule owner; merge only when it becomes a stable general rule. |
| `provenance/`, `references/`, `research/` | Origin records and non-product research. | Source owner; never becomes a runtime dependency without an approved task. |
| `release/` | Release templates and procedures. | Release owner; retain while the release form is supported. |
| `requirements/` | Detailed compatibility and fixture requirements supporting `design/REQUIREMENTS.md`. | Product owner; merge when they become a stable top-level requirement. |
| `legacy-history/` | Read-only aggregation retained during migration to numbered task history. | Documentation owner; do not use as current planning authority. |
