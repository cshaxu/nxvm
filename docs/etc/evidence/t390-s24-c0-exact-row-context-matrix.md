# T390 S24: M40-C0 Exact-Row And Context Matrix

## Authority And Method

This matrix consumes the frozen 75-unit M40-C0 universe in the S23 convergence ledger. Intel, *80386 Programmer's Reference Manual* (1986), section 17.2.2.3, Table 8-1 and the individual instruction pages are the primary timing authority; the repository's T357, T359 and T390 evidence records retain their exact row crosswalks. The 80386 rows are Core clocks under the manual's prefetched, no-wait and no-HOLD assumptions. They do not establish device service, bus, board or L3 time.

The matrix does not infer a source row from an emitted tick count. A unit is source-sufficient only when its retained normalized form/context selects one existing exact row. It remains nonphysical until the named receiver supplies its C0-focused project-owned regression and the complete C0 batch has no unresolved member. A Blocked unit has a concrete missing fact; it stays rejected before physical elapsed-time publication.

## Batch Reconciliation

The matrix covers C0-001 through C0-075 exactly once: 75 aggregate units and 18,255 successful classified retirements. It records 44 source-sufficient units as Deferred/nonphysical pending one C0 direct-row regression batch, and 31 Blocked units in four complete shared capture receivers: control context (17), primary shape (7), string continuation (2), and privileged selector/target (5). No unit is Accepted or physically eligible in this S.
