# Source And License Boundary

The canonical policy is [../source-policy.md](../../rules/SOURCE.md). This entry
adds release obligations for the current governance layout.

Project-owned files and NXVM-derived units imported under the NXVM copyright
holder's authorization use the root MIT License. NXVM imports retain copyright
attribution and provenance records. The separate NXVM repository's historical
LGPL metadata does not govern authorized ntvdm64 imports. A file with an
independent third-party notice requires a separate review before import.

Before M1 imports NXVM source, the repository contains no NXVM-derived unit and
the root MIT License governs all repository material.

Historical third-party VDM implementations are research sources only. WineVDM
remains an external GPL-2.0 research candidate unless a separate approved
distribution decision says otherwise. Microsoft guest binaries are neither
committed nor distributed; any BYOB proposal requires a future M11 Go decision.
