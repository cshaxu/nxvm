# Selected Board And Source Freeze

## Objective And Owners

First M1 candidate: freeze one original V30-based RAIDEN II board/game set,
lawful owner assets and implementation evidence. Owns MyRaidenII design,
research, ROM-free inventory validation and its finite convergence ledger.
It does not allocate M1 T1 before owner admission.

## Work And Decisions

Inventory program, graphics, sound, sample and protection payload roles,
actual file sizes and hashes in the external owner archive; distinguish ROM
contents from emulated address-region size. Fix revision/region and startup,
attract, coin/start, gameplay, stage/boss/end, game-over and restart checkpoints.
Acquire CPU/device manuals and pin reference revisions/licenses. Determine
V30 versus existing X86 Core reuse, public bus/time boundaries and source grades
before CPU implementation; do not assume 8086 or 386 equivalence.

## Exit And Stops

Every selected capability has one owner, source grade, input, observable result
and test location. Missing assets/evidence remain explicit prerequisites, not
success. Review any Shared API or third-party source choice separately. No ROM
download/commit/embedding, later V33/DX substitution or game/protection bypass.
