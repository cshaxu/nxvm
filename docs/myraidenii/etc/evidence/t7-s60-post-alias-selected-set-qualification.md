bounded COP alias completion.  Each supported host width reached the existing

No guest bytes, addresses, instructions, register values, media payloads,
screenshots, raw frame content or third-party source were retained.

child.  Existing x64/x86 probe targets built successfully in their stable

diagnostic.  A later receiver must choose a distinct, source-policy-compliant
qualification question—such as bounded presentation, control, audio or
