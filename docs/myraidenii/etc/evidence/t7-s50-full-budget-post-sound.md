## Scope And Asset Boundary

This receiver repeats S40's registered maximum-budget qualification only after
S41--S48 complete the transferred local Sound CPU work.  It uses the existing
vblank-aligned Coin/Start route; it changes no emulator behavior.  The external
wrapper verified the owner archive through the recorded inventory, staged only
the required images below the external diagnostics root, and removed each
generated staging child.  No protected payload, guest byte/address/trace or
third-party source is retained here.

## Deterministic Result

Both host widths delivered all four existing vblank-aligned input edges and
then reached the same finite CPU-internal case-error-class terminal at
43,714,177 executed instructions, before the 100,000,000 containment budget.
Neither run reports the former Sound decoder category, a COP terminal, or a
Board control failure.  The matching result proves that S40's former Sound
receiver is crossed, but does not identify the operation responsible for the
new Core terminal.

The aggregate output confirms that the existing Video, input, Sound transport,
interrupt and sprite-protection owners remain active before the terminal.  It
does not prove accepted credit, title screen, gameplay, rendering fidelity,
sample playback, desktop behavior, RDP behavior or release readiness.

## Receiving Boundary

The terminal is an X86 Core case-error-class failure, not an App-local Sound
decoder, Board control or COP admission result.  A follow-up must first
classify the existing X86 Core case-error owner and audit its complete local
instruction/format family before any implementation is selected.  The
observation does not license a special-case exception suppression or an
address-specific route.
