## Outstanding CHKIND Decision In Concrete Terms

For bounds0000..FFFF and index8000, the existing signed predicate rejects
because its upper bound is-1; the proposed unsigned L2 accepts. For
bounds8000..7FFF, the signed model describes the whole signed-word range,
whereas the unsigned model has an inverted/empty interval. Ordinary positive
in-range values agree. Thus changing this predicate is an actual V30 behavior
change, not a type-only cleanup, and remains unimplemented pending the owner.

If approved, keep the existing16-bit BOUND/CHKIND execution handler, pair-read,
exception5 entry, flags and timing owners. Select unsigned comparisons only
for the V30 profile; retain signed Intel BOUND16/32 behavior. The existing
software_entry oracle changes its V30 interval predicate and retains its
addressing, flags, full frame/IRET and failure matrix. Add explicit contrast
witnesses if the original input matrix does not already distinguish the two
models. Expected production+4--8/-1--3, tests+10--30/-1--4; no function, type,
callback, mode state or public contract is added. The fixed reference supports
this as L2, not a primary-manual or silicon-exact assertion.
