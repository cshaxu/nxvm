# Gameplay And Release Qualification

## Objective And Prerequisites

Complete the entire frozen game/board convergence ledger after CPU, bus/COP,
video, sound and real Product integration. A working title screen is not exit.

## Work And Verification

Run reproducible owner-ROM startup/attract/coin/start, player controls, stage
and boss transitions, end/game-over/restart checkpoints with sound and graphics.
Measure host execution efficiency separately from authentic guest slowdown.
Exercise lifecycle/input reset, missing/corrupt assets, bounded failures and
cleanup through production composition, not disconnected validators.

## Exit And Stops

Both host widths pass all owned units, required native/owner-ROM integrations
and affected Shared consumer regressions. Existing Ninja/ccache graphs reuse
shared objects per architecture. Review actual diffs, source provenance and
manifest/boundary gates; deploy only the latest pair with verified identity.
Record any unexecuted desktop/RDP/physical-audio checks separately and obtain
owner gameplay acceptance. Do not close by reducing checkpoints or transferring
unfinished required behavior into an unadmitted successor.
