# DeskPro 386 Profile And 80386 CPU Closure

## Purpose

Select one exact Compaq DeskPro 386 configuration and close the 80386 CPU,
paging, protection, delivery and successful-retirement ledger needed by that
profile.  This is the first of three bounded DeskPro candidates; it does not
allocate board bus or device-service timing.

## Required scope

Choose the documented DeskPro model/revision, 80386 clock, chipset, RAM,
ROM-slot boundary, display/storage selection and project-owned corpus.  Build
the source-labelled 80386 form/state matrix for the selected CPU: 32-bit
width, paging, VM86, privilege, exception/interrupt delivery and system state
only where each is required by the selected profile or corpus.  Reconcile all
remaining 80386 source rows through the shared four-profile program, preserving
each 16-/32-bit architectural layout and one retirement publisher.

## Non-goals and stop conditions

No board wait state, ISA/DMA arbitration, PIC/PIT/RTC/KBC/display/storage
service timing, NMI route, physical clock or Windows claim.  Stop if the exact
machine/corpus cannot make a CPU state distinction observable; transfer it to
the source ledger rather than infer it from a generic 386 PC.

## Evidence standard

Require exact profile provenance, CPU source/form/state ledger, caller and
publication sweep, focused paging/delivery/timing proof, retained earlier-CPU
regressions and an explicit handoff to the DeskPro board timing candidate.
