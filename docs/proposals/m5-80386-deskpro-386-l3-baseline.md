# Compaq DeskPro 386 80386 Baseline-Machine L3 Closure

## Purpose

Establish one exact Compaq DeskPro 386 80386 baseline machine after the IBM
PC/AT 5170 closure and before the 8088/IBM 5150/XT baseline and Windows 3.x
work. The admitting task selects the precise DeskPro model/revision, 80386
clock, chipset, memory, ROM, display/storage adapters, and project-owned probe corpus; "DeskPro 386"
alone is not a timing contract.

## Required scope

Map the selected 80386 CPU and paging/interrupt state together with board
memory/I/O availability, DMA, PIC, PIT/RTC, keyboard, display, storage, NMI
and reset routes to one source-labelled L3 model. Reconcile the established
80386DX instruction/state ledgers with the physical profile without using a
later CPU or generic PC/AT assumption to fill a board fact. Primary Compaq,
Intel and device documentation plus project-owned probes are required; 86Box,
MAME and PCjs may only cross-check a primary-constrained range or an explicitly
recorded measurement contract.

## Non-goals and stop conditions

No unspecified DeskPro revision, 486+ inference, VME/PVI or x87 numeric claim,
universal 80386 PC timing, copied emulator code, host-time coupling, Windows
claim, or firmware/media import. Stop if the selected board/corpus cannot make
one availability, device or NMI route observable; transfer it rather than
borrowing 5170 timing.

## Evidence standard

Require exact profile provenance, CPU/bus/device/NMI source ledger,
source-to-model or reference-exhausted timing table, paging/IRQ/DMA contention
and reset replay, project-owned firmware/DOS probes, full current-gate evidence,
and a closure matrix that keeps this board distinct from the 5150/XT and 5170.
