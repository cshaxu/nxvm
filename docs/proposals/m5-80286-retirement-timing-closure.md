# 80286 Successful-Retirement Timing Closure

## Purpose

Complete the source-labelled 80286 successful-retirement timing ledger that
T366 S32 transferred before a PC/AT board-clock or bus-availability claim.
This candidate consumes the accepted T366 S11--S31 rows and their publisher
inventory; it does not reopen the Model 339 topology or claim 5170 L3.

## Required scope

Start from every remaining successful 80286 instruction/form/state row,
including default and prefixed forms, system/control families and each mode,
privilege, operand and descriptor condition that selects a source value.  Each
row must either publish one Intel-primary exact value through the existing
retirement owner, be reduced by a documented same-profile model only when the
Intel authority permits it, or transfer once with an exact admission condition.
No successful fallback value may remain eligible to masquerade as a physical
8 MHz clock.  Reconcile the result with the shared four-profile program
without borrowing an 80386 value for 80286.

## Non-goals and stop conditions

No CPU fetch/bus phase, memory or I/O wait state, DMA arbitration, device
service time, board timing, physical-clock conversion, firmware/media import
or 5170 L3 claim.  Stop a row when the documented source cannot distinguish
its required successful context; retain a visible receiver rather than invent
a scalar.

## Evidence standard

Require a complete source/form/context ledger, one successful-retirement
publisher audit, focused semantic-and-timing proof for each admitted family,
the current gate, and a closure matrix showing that every remaining successful
fallback either disappeared or has one named receiver.  This is the CPU
prerequisite for PC/AT bus availability; it is not a substitute for it.
