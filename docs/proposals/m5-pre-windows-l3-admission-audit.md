# M5 Pre-Windows L3 Admission Audit

## Purpose

Make the explicit L3 admission decision before any Windows 3.1 harness,
Standard Mode or 386 Enhanced Mode task may start.  This is the program-level
gate after the 5170, DeskPro Model 40, 8088/PC/XT 5160-268 and current-product
device closures.

## Required scope

Independently review each frozen baseline and every currently supported product
device capability.  Prove that the 80286, 80386 and 8088 CPU ledgers, board
availability, service timing, event ordering, reset/cancellation paths and
profile identities have source-backed or explicitly model-derived L3 evidence,
with all reference-exhausted boundaries visible.  Decide whether the frozen
DeskPro Model 40 profile is admissible as a Windows compatibility consumer.

## Non-goals and stop conditions

No Windows media, harness execution, implementation repair, M6 admission or
new machine selection.  A missing proof or reproduced defect returns to its
earliest Queue owner and blocks Windows admission.

## Evidence standard

Require a cross-profile/device closure matrix, independent current-gate rerun,
profile/artifact identity proof, residual-debt check and an owner-visible
admit/not-admit decision.  Only an explicit admit unlocks the Windows
candidates.
