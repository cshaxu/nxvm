# Architecture Direction

The canonical architecture is [../architecture.md](../architecture.md). This
compatibility entry remains so older links resolve.

The controlling direction is NXVM-derived machine code, a separate owned DOS
module, non-invasive Windows platform adapters, and isolated invasive-
integration research. Microsoft NTVDM component feasibility is a post-M5
research topic, not a backend. Do not treat this file as a second architecture
specification.
