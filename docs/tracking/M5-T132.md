# M5 T132: Production State-Selection Audit

## Result

The production source scan found no `_Thread_local`, `__thread`, or C11
`thread_local` selection state; no remaining ambient wait enter/leave API; no
`src/core` include of `vm/` or `vdm/`; and no static global session, machine,
or context pointer. Static callback functions accept their owner through a
`C_VOID *context` parameter and are not current-object facades.

The current NXVM product path is singular:
`src/vm/main.c` creates one `vm_session`, enters its Console, and its runner
calls `core_machine_run`. VDM has no product executable entry yet; its minimal
session only creates the shared executor-backed skeleton and never starts a DOS
execution loop.
