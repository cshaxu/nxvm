# M5 T154: CPU/FPU Profile State And Metadata

## Result

`core_machine` now owns immutable CPU and FPU profile selections. A zeroed
legacy config resolves to `80386+none`; explicit configurations accept each
planned CPU and FPU model. The new metadata contract classifies primary, `0F`,
and FPU escape forms without changing existing decoder behavior.
