# M5 T196: Linux Run-Handle And POSIX Evidence

Status: complete with owner-approved native-runtime deferral.

## Objective

Make the Linux Console use the same session-owned run-handle rules as Win32,
then obtain native POSIX compile and runtime evidence. Windows source checks
are useful preparation only and cannot close this task.

## Implemented Source Contract

- CMake chooses only Win32 platform sources on Win32 and only Linux platform
  sources elsewhere; Linux links `Curses` and `Threads`.
- Linux display initialization reports `STARTUP_FAILED`; the start path waits
  for display readiness or failure, then performs the existing stop/join/
  finalize cleanup before returning a failure.
- Linux F9 reports `STOP_REQUESTED`; the composition runner consumes it.
- Linux workers remain joinable and only the finalizer calls `endwin`, releases
  the terminal lease, frees the backend, and clears the embedded owner.

## Deferred Native Evidence

1. Configure with a 64-bit GCC or Clang plus `ncurses` development headers and
   pthreads; run `tools/Verify-T196-Posix.sh`. It builds `vm-0-5-0196`, the
   cross-platform event smoke, and a Linux terminal run-handle smoke. The
   latter executes two start/report-stop/join/finalize cycles under a pseudo
   terminal and requires each to leave no live handle/backend.
2. In a real terminal, run the normal Console, F9 cancellation, guest
   completion, terminal-lease contention, and FDD DOS-prompt probes.
3. Run a terminal-initialization failure probe (for example a deliberately
   unusable `TERM`) and verify start failure leaves no live handle or lease.
4. Record compiler, terminal, commands, markers, artifact identity/hash, and
   cleanup of temporary build trees in `docs/verification/`.

## Owner-Approved Deferral

The owner directed that no WSL installation be attempted and that complete
Linux code/CMake convergence is sufficient for T196. This Windows host has no
installed Linux compiler or runtime, so the local
`verify-linux-platform-contract` result is source-only evidence. The native
commands above remain an open `TODO.md` item; this task makes no claim that
Linux execution has been validated or supported.
