# M5 T161: VM Provider Composition Separation

## Result

`vm/composition/session` no longer contains the mixed `providers.*` source.

- `machine_devices.*` owns VM-only CMOS, FDD, FDC, and HDD lifecycle and the
  required non-owning core capability bindings.
- `profile_firmware.*` owns default-profile BIOS/QDX initialization, POST/IVT
  registration, reset, refresh, and finalization.
- `provider_lifecycle.*` is the one thin coordinator. It preserves the former
  device/firmware call order and remains the only execution-provider bridge.
- `machine_info.*` owns the Console-facing machine-info adapter.

The coordinator owns neither device/profile state nor core lifecycle. The
static `verify-vm-provider-composition` target rejects the removed mixed files
and direct device, profile, or core-borrow implementation inside the
coordinator.
