# M5 T197: Current Artifact Build Graph

Status: complete.

## Objective

Remove stale historical task/version executable targets from the active CMake
graph. Historical task artifacts remain immutable local evidence under
`build/output/`; only the current source version may be built as a product
artifact.

## Scope

- Delete `add_vm_task_artifact` and all historical
  `add_vm_version_artifact` registrations.
- Retain one accurately named current-artifact helper and `0.5.0197` target.
- Make the GCC current preset select only that target.
- Add a source/CMake gate that rejects historical helpers, multiple current
  artifact targets, or preset/version drift.

## Non-Goals

- Do not delete retained local artifact files or rewrite historical evidence.
- Do not change NXVM Console, debugger, machine startup, or guest behavior.

## Required Evidence

- Fresh CMake configure; current artifact and all applicable current gates
  build successfully.
- `verify-current-artifact-target` emits its success marker.
- `nxvm_0_5_0197.exe` prints its matching banner and accepts `EXIT`.
- CMake target listing contains exactly one product artifact target.

## Verification

  current-gate preset.
- `verify-current-artifact-target` emitted
  `M5:T197:S1:CURRENT-ARTIFACT-TARGET:OK`; its source scan rejects both former
