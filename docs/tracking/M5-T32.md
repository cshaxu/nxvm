# M5 T32: Core-Machine Interface Naming

## Status

Complete.

## Contract

`*_interface.h` names a public cross-module contract. `machine.h` is private
to `core/machine`. External callbacks enter as `*_provider` values, and their
binding names end in `_bind_provider` or `_install_provider`.

## Acceptance

No behavior or user-interface change; Windows GCC, focused core-machine
smokes, dependency DAG, retained Console/debugger smoke, and
`build/output/nxvm-m5_t32.exe` must pass.

## Result

The public contracts now use explicit `*_interface.h` names; `machine.h` is
private implementation state; and port, trace, display, keyboard, and block
callback inputs use `*_provider` names. See
`docs/verification/m5-t32-s1-interface-naming.md`.
