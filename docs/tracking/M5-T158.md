# M5 T158: CPU And FPU Static Closure

## Result

The CPU/FPU profile sequence now has two repository-owned closure gates:

- `nxvm-core-machine-cpu-fpu-profile-closure-smoke` enumerates primary, `0F`,
  and FPU escape opcode/ModRM metadata and verifies every entry carries valid
  CPU/FPU bounds. Every `D8`--`DF` form is a valid FPU escape with minimum
  `8086`/`8087`; other escape-space opcodes are explicitly invalid.
- `nxvm-cpu-fpu-static-closure` scans the authoritative decoder source and
  rejects the historical unconditional `i386(...)` compatibility gate and any
  direct `D8`--`DF` table assignment to `UndefinedOpcode`.

These gates close only the profile, dispatch, and absence behavior introduced
by T153--T157. They do not claim full 80386 coverage or usable present-FPU
profiles.
