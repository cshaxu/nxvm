# M5 T195: Win32 Run-Handle Failure Paths

Status: complete.

## Objective

Prove every native Win32 partial-start branch preserves the single session-owned
run handle: failure requests stop where necessary, joins already-created
workers, releases the one backend/renderer/lease, and leaves the owner
inactive and reusable.

## Design

S1 records one test-only compile-time stage contract. S2 applies it only at
existing Win32 native creation/initialization failure branches. S3 builds each
stage in an isolated build directory and runs a smoke that verifies failed
start postconditions followed by a clean handle/lease acquisition.

Stages cover window display-thread creation, class/window/renderer startup,
window kernel-thread creation, Console renderer creation, Console kernel-thread
creation, and Console display-thread creation. The normal GCC preset carries
no test definition and continues to exercise the unmodified release path.

## Required Evidence

- Each injected stage returns a defined failure result and leaves `active == 0`
  and `backend == NULL`.
- A follow-up normal start can acquire the same host resource.
- Existing Console lifecycle, window cancellation, two-session, and DOS-prompt
  gates remain green in the normal build.
- `nxvm_0_5_0195.exe` is produced from the normal GCC preset.

## Stop Conditions

Stop before continuing if the test mechanism enters a release artifact, adds a
global/current-session selector, changes Console grammar/window behavior, lets
a worker free shared state, or masks a branch rather than exercising its real
cleanup path.

## Verification

- Eight independent MinGW build trees, one per stage, emitted
  `M5:T195:S3:WIN32-STARTUP-FAILURE:<1..8>:OK`. Every staged start failed
  twice in one initialized session and returned with an inactive run handle
  and null backend. The second attempt proves the first path released its
  handle and, for Console stages, its host-surface lease.
- The normal `mingw-gcc-x64` cache records
  `PROJECT_VM_PLATFORM_TEST_FAILURE_STAGE:STRING=0`; its compile database has
  no injected definition.
- Normal focused smokes emitted `M5:T194:S3:RUN-EVENT:OK`,
  `M5:T149:S1:MULTI-WINDOW:OK`, `M5:T73:S1:TWO-SESSION-ISOLATION:OK`, and
  `M5:T70:S2:DOS-PROMPT:OK` with
  `D:\\home\\repos.hobby\\fdd.img`. The configured GCC gates also passed.
- The normal artifact accepted piped `EXIT` and printed
  `Neko's x86 Virtual Machine [0.5.0195]`.
