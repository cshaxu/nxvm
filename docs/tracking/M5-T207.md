# M5 T207: Linux Console Private Naming Cleanup

Status: complete.

## Objective

Make Linux Console private helpers readable under the established owner-prefix
style without splitting its cohesive adapter implementation.

## Scope

- Replace `GetMin` and `send` macros with typed private functions.
- Rename local display, keyboard, color, and character helpers to
  `vm_platform_linuxcon_*`.
- Rename the two Linux Console adapter calls consistently in their local header
  and caller.
- Extend Linux adapter hygiene evidence and advance the artifact to `0.5.0207`.

## Non-Goals

- Do not change curses rendering, scan-code translation, threading, run-handle
  lifecycle, color mapping, or public cross-module platform contracts.

## Rules And Stop Conditions

- `RULES.md`: keep the cohesive adapter in one file and use accurate

- `execution-policy.md`: static Linux source evidence is distinct from deferred
  POSIX native compilation; current GCC/CTest evidence remains required.
- Stop on changed Linux source contract, input/display semantics, or any
  current smoke regression.

## Required Evidence

- Current GCC gates and a `0.5.0207` Console `EXIT` artifact pass.
