# M5 T204: CMake Media Smoke And Linux Adapter Hygiene

Status: complete.

## Objective

Make current media smoke classification single-sourced and remove confirmed
Linux/Win32 platform-adapter dead noise without changing tests or runtime
behavior.

## Scope

- Define FDD-only and FDD+HDD smoke targets once, then derive both generic
  registration skipping and media-argument registration from those lists.
- Remove only the uncalled Linux sleep function, uncalled Win32 sleep macro,
  unused Linux Console constants/includes, and unreachable switch residue.
- Add static gates for the CMake classification and Linux adapter cleanup.
- Advance the current task artifact to `0.5.0204`.

## Non-Goals

- Do not change smoke target membership, guest-media arguments, Linux behavior,
  Console behavior, run-handle ownership, or platform APIs with callers.

## Rules And Stop Conditions

- `RULES.md`: preserve product behavior and module boundaries; no new wrapper
  or platform-to-guest dependency is admitted.
- `execution-policy.md`: current gates must execute CTest; static gates must be
  named as static checks; one task artifact records the result.
- Stop if current CTest membership/arguments differ, if a removed symbol has a
  caller, or if GCC/Console smoke regresses.

## Required Evidence

- Static gates prove the media lists are the only registration source and the
  removed adapter symbols/residue do not return.
- Current GCC gates and a `0.5.0204` Console `EXIT` artifact pass.
