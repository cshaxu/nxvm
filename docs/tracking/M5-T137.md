# M5 T137: Narrow VM Execution Context Ownership

| Subtask | Scope | Status | Evidence |
| --- | --- | --- | --- |
| S1 | Move and rename the VM-only execution-control context from `core/product/runtime` to `vm/composition` | Complete | [`m5-t137-s1-vm-session-execution-context.md`](../verification/m5-t137-s1-vm-session-execution-context.md) |

## Contract

- **Objective:** make the type and file location state that the context belongs
  to one `vm_session` control object, not to shared core product runtime.
- **Non-goals:** change CPU execution, lifecycle ordering, Console grammar,
  debugger behavior, VDM, or add a second session model.
- **Reference:** `nxvm_0_5_0129.exe` and the retained FDD DOS-prompt smoke.
- **Surface:** `core_product_execution_context_*` becomes
  `vm_session_execution_context_*`; source moves to
  `src/vm/composition/session_execution_context.*`.
- **Gates:** dependency-DAG configure, Windows GCC build, execution-context,
  Console lifecycle, two-session isolation, and FDD DOS-prompt smoke tests.
- **Stop:** stop on any core-to-VM dependency, lifecycle ordering change,
  Console/debugger regression, or FDD DOS-prompt failure.
