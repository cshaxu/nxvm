# M5 T198: Current Smoke Execution

Status: complete.

## Objective

Make `current-gates-gcc` truthful: build every selected current smoke
executable, execute it through CTest, and separately run static source gates.

## Scope

- Register the existing configured runnable smoke set as labeled CTest cases.
- Add one CMake target that builds that set and invokes CTest with
  `--output-on-failure`.
- Replace the compile-only smoke target list in `current-gates-gcc` with that
  execution target; retain static verification targets explicitly.
- Advance the current task artifact to `0.5.0198`.

## Non-Goals

- Do not expand the smoke corpus or claim native Linux runtime coverage.
- Do not alter NXVM Console, debugger, guest startup, or device behavior.
- Do not remove standalone focused smoke targets used by historical evidence.

## Required Evidence

- A clean GCC configuration discovers the labeled current CTest set.
- `cmake --build --preset current-gates-gcc` executes it successfully and
  exposes CTest failure output if any smoke fails.
- Static gates remain distinct in the preset output.
- `nxvm_0_5_0198.exe` prints its matching banner and accepts `EXIT`.

## Verification

- Fresh MinGW GCC configuration registered 40 `current.*` CTest cases.
- `cmake --build --preset current-gates-gcc --parallel 1` built and executed
  all 40 cases: `100% tests passed, 0 tests failed`. It then ran the separate
  dependency, ownership, lifecycle, Linux source-contract, and artifact-target
  static gates.
- Fixture-dependent tests receive the owner-provided, untracked sibling
  `fdd.img` and `hdd.img` paths through cache variables rather than implicit
  process state.
- The executor smoke now runs `NOP; HLT`, so it proves both a budget boundary
  and a following halt boundary. The DOS MEM smoke observes a diagnostic only
  after its guest worker stops; a running guest is a valid no-fault outcome.
- `nxvm_0_5_0198.exe` printed `Neko's x86 Virtual Machine [0.5.0198]`,
  accepted piped `EXIT`, and has SHA-256
  `6B40CA27D30B5C216F68A195E7CC9560151A56891672F3D6A50AA9CA1B1637AB`.
