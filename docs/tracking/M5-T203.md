# M5 T203: Console Adapter Readability And Selected Borrow Closure

Status: complete.

## Objective

Keep the Console machine-provider vtable as the product/composition boundary,
while making each callback readable and using one typed selected-session borrow
helper.

## Scope

- Add one Console adapter selected-session borrow helper. The duplicate unused
  factory-local helper is removed.
- Expand Console machine-provider callbacks into ordinary functions without
  changing their signatures, order, or Console-visible behavior.
- Preserve debugger pause, two-second wait, debug-context initialization,
  flush provider, and debugger entry order.
- Add a source closure gate and advance the current artifact to `0.5.0203`.

## Non-Goals

- Do not remove the vtable, alter selected-session policy, change Console
  grammar, add session selection state, alter debugger UX, or refactor core
  session-manager ownership.

## Rules And Stop Conditions

- The helper borrows and owns no session state.
- A failed selected borrow must retain each callback's prior null/no-op or
  error-return behavior.
- Stop for Console/debugger, boot/media, selected-session, or two-session
  regressions.

## Required Evidence

- Static gate proves exactly one composition call to the core selected-borrow
  API and the adapter uses the typed helper.
- Console lifecycle, debugger, two-session, media/boot, current gates, and a
  `0.5.0203` Console `EXIT` artifact pass.
