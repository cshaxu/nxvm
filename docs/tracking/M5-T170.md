# M5 T170: Cold-Start Lifecycle

## Result

- `core_machine_reset` ends in `STOPPED`.
- `core_machine_run` starts a cold-reset stopped machine or resumes a paused
  machine.
- A stop request performs one core cold reset before it publishes `STOPPED`.
  The reset/provider trace is therefore ordered before the stop trace.
- Public memory, port, and A20 helpers accept both safe returned boundaries:
  `STOPPED` and `PAUSED`.
- A core guest-reset request resets in core; VM resets only VM-private debug
  state after the returned result, avoiding a second core reset.
