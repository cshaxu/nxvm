# M5 T201: Host Cancellation Boundary Convergence

Status: complete.

## Objective

Make the run handle the sole platform-to-session host-cancellation boundary.
Windows and Linux F9 both report `VM_PLATFORM_RUN_EVENT_STOP_REQUESTED` on the
live backend-owned handle; only the session runner consumes that report and
requests guest stop.

## Scope

- Remove `request_stop` from `vm_platform_keyboard_sink` and delete its
  transport operation and session callback.
- Pass the borrowed live run handle to the Win32 key handler. F9 reports to
  that handle, matching the Linux Console implementation.
- Preserve historical guest F9 key forwarding after the host report; this task
  changes the cancellation control boundary, not guest key mapping.
- Add focused F9/report, runner-consumption, and static source-closure proof;
  advance the current artifact to `0.5.0201`.

## Non-Goals

- Do not create an egress queue, a second cancellation channel, a session
  callback in platform, or a platform-to-core dependency.
- Do not alter KBC, QDKEYB, scan-code mapping, window lifecycle, Console
  grammar, debugger behavior, or Linux native verification status.

## Rules And Stop Conditions

- Keyboard transport carries only modifier reads and guest key presses.
- Backends borrow their run handle while it is live; they report but never
  call session control, core stop, join, finalization, or resource release.
- Runner consumption remains the only report-to-session-control transition.
- Stop for changed F9 guest delivery, a direct platform session/control call,
  a second host-cancellation route, run-handle ownership regression, or a
  retained Console/debugger/FDD DOS-prompt failure.

## Required Evidence

- Focused Windows F9 smoke proves one stop report and retained guest key ingress.
- Run-handle smoke proves the runner consumes a report at its existing boundary.
- Static gate rejects keyboard lifecycle callbacks and platform session/control
  dependencies, and requires matching Win32/Linux F9 report calls.
- Current CTest/static gates and a `0.5.0201` Console `EXIT` artifact pass.
