# M5 T157: Session CPU And FPU Profile UX

## Result

NXVM Console now accepts:

```text
SESSION OPEN [--cpu <8086|80186|80286|80386>] [--fpu <none>]
```

The generic core session manager transports opaque creation options only. VM
composition parses them, produces the frozen `core_machine_config`, and owns
the model policy. Session 0 and omitted options resolve to `cpu=80386
fpu=none`; `SESSION LIST` prints each session's immutable selection.

Present FPU values parse as known model names but reject with `Requested session
configuration is unavailable.` until a later implementation supplies their
state and operations. No profile has a hot-switch path.

The NXVM banner now reports the required 2012--2026 copyright while retaining
the bootable NXVM product name.
