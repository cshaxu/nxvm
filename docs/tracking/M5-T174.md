# M5 T174: RAM Cold-Reconfiguration Closure

## Result

T174 adds `verify-ram-reconfigure-closure`, which requires the core
stopped-only cold-reset operation, rejects legacy raw-address and non-core
backing access, and verifies that the VM route does not rebuild a session.
T165 remains historical transition evidence only; it no longer describes the
active path.

The retained core executor smoke is updated to honor T160's frozen-provider
lifecycle: it installs the explicit 80386 reset-vector mapping while
configuration is open, then writes its test HLT through the stopped public
memory interface rather than borrowing configuration-only RAM after freeze.
The CPU fault-diagnostic smoke likewise configures its test CPU state through
the stopped debug boundary and writes its test program through the public
stopped memory interface.
The keyboard ingress smoke now reads the BIOS buffer through that stopped
debug boundary rather than using a closed configuration borrow.
The VM debugger-target smoke now establishes the session's cold `STOPPED`
boundary before exercising debugger access, matching the public contract.
