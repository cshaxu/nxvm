## Boundaries

- **Objective:** approve a single session-owned run handle before changing
  Win32 or Linux thread code.
- **Non-goals:** serialize kernel/display work, change retained Console
  grammar, change window startup behavior, or finalize a session from a worker.
- **Stop:** do not begin T139 until creator, joiner, destroyer, worker event,
  failed-start, Console exit, Console stop, and window-close ownership are
  unambiguous.
