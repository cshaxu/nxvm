# M5 T167: VM Session Factory and Console Adapter Split

## Scope

Split the old mixed VM session-provider source without changing NXVM Console
grammar, selected-session behavior, debugger behavior, or boot flow.

## Result

- `session_factory.c` owns option parsing and the session-provider
  `open`/`describe`/`close` callbacks.
- `console_machine_adapter.c` owns the selected-session lookup and the existing
  Console machine-provider callbacks.
- `provider.h` remains the stable declaration point; no compatibility wrapper
  or second session object was added.
