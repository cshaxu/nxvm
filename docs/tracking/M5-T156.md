# M5 T156: FPU ESC Absence And FWAIT Behavior

## Result

`D8` through `DF` now dispatch through the core-owned FPU escape path with the
actual escape opcode and ModRM form. The default `FPU=none` configuration
consumes the complete encoding without arithmetic or memory side effects.
`CR0.EM` or `CR0.TS` produces `#NM`; a configured present FPU reaches the
explicit unimplemented-model diagnostic instead of `#UD`.

FWAIT now follows the required `TS && MP` gate. The FDD `MEM` smoke reaches
`FNINIT` and remains alive through the bounded post-command observation rather
than stopping at `DB E3`.
