# M5 T155: Centralized CPU Profile Gating

## Result

The decoder now makes CPU availability decisions at the primary and `0F`
dispatch boundaries from T154 metadata. Unavailable forms reach `#UD` before
their handler decodes operands. The legacy unconditional `i386(n)` macro is
gone; retained handlers select their historical 16/32-bit implementation path
from the frozen context profile.

`F1` is explicitly classified as the default-profile QDX reserved escape at
the 80386 level. It remains unavailable to lower profiles while preserving the
existing profile-installed firmware path.
