# M5 T160: Public Lifecycle Hardening

## Intended Result

`core_machine` has one configuration window: after creation, composition may
install execution and port providers. `core_machine_freeze_execution_providers`
closes it once. `core_machine_reset` then establishes `PAUSED`, and only a
bounded `core_machine_run` enters `RUNNING`.

Public physical-memory, port, and A20 operations are command-boundary APIs;
they reject every lifecycle state except `PAUSED`. VM/VDM-only provider
callbacks still operate through their bound core objects during guest execution
and do not use those external APIs.
