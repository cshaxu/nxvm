# M5 T172: Core-Owned Stopped RAM Reconfiguration

## Result

- `core_machine_reconfigure_memory(machine, bytes)` retains the existing core
  machine and all CPU/shared-device/provider objects.
- It is available only after provider freeze and only while lifecycle is
  `STOPPED`.
- It validates the configured RAM range and retained explicit mapping targets,
  replaces one backing allocation, and invokes the ordinary cold-reset path.
- `INITIALIZED`, `PAUSED`, `RUNNING`, and `FAULTED` calls are rejected.

## Verification

- `nxvm-core-machine-memory-reconfigure-smoke` proves CPU/RAM-object identity,
  provider reset count, zeroed replacement backing, new installed size, and
  rejected lifecycle states.
- The retained Console and FDD DOS-prompt gates remain required for task
  closure.
