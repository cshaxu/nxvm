# M8 Compatibility Corpus Policy

Before M8 implementation, declare each corpus entry's legal acquisition basis,
logical identity, hash, execution profile, required features, expected output or
state, known limitations, and automated/manual verdict. The initial corpus must
separate redistributable project probes from local owner-provided programs.

Prioritize entries by user value and the smallest missing compatibility feature.
An entry cannot broaden M8 by itself: a new feature needs an evidence record,
an owner-approved scope decision, and a focused regression test.
