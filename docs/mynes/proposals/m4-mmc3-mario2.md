# M4 Mapper-4 Super Mario Bros. 2 Path

## Outcome

Deliver the bounded MMC3 cartridge profile and make the owner-local Super Mario
Bros. 2 support input pass strict removable-media insertion. Gameplay controls
and both KVM routes remain owned by the later APU/audio acceptance path.

## Acceptance

Project-owned fixtures prove MMC3 bank modes, mirroring and qualified PPU A12
IRQ behavior through production machine timing. The owner-local scenario proves
only bounded removable-media insertion; execution stops are recorded as APU work
until its dedicated M4 receiver supplies the missing hardware and audio path.
