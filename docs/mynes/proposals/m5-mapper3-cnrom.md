# M5 Mapper 3 CNROM

## Outcome

Implement the declared Mapper 3 CNROM profile: fixed PRG, switchable CHR, fixed mirroring and explicit legacy/submapper bus-conflict behavior.

## Acceptance

Project-authored production fixtures prove every CHR bank, reset state, wrap/rejection rules, mirroring and both bus-conflict dispositions. No unprovided commercial ROM is required; the final compatibility matrix records Mapper 3 fixture qualification separately from the six supplied-input runs.
