# M5 Admission Record

## Admission

The owner admitted M5 on 2026-09-22 after M4's final closure audit. M4 is the
accepted predecessor; its finite game-support obligations do not transfer as
open defects.

## Fixed Boundary

M5 retains the approved roadmap scope: a finite declared extension of mapper,
ROM-format and hardware coverage; cartridge-appropriate persistence,
configuration saving and reproducible release delivery. Its exit requires one
declared support/regression matrix, known limits and reproducible release
evidence. It does not imply universal NES compatibility, save states, replay,
rewind or networking.

## Planning Boundary

Admission authorizes a later M5 planning task. It does not allocate numeric
implementation tasks, select compatibility targets, introduce source imports,
or change code, tests or artifacts. The future planning task must first define
the finite support matrix, persistence semantics, release baseline and proof
obligations before implementation task admission.

## Delivery

M5 admission is documentation-only. The repository has no configured remote,
so the approved delivery rule uses a local commit rather than a push.
