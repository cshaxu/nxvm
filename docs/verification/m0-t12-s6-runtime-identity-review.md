# M0 T12 S6 Runtime Identity Review

## Result

The byte-identical M1 baseline keeps its imported NXVM banner. Starting with the
first M3 refactored runnable machine artifact, standalone-machine builds use
the `0.4.015d.m<M>t<T>s<S>` identity. The exact Virtual DOS Machine banner and
`DDDH` version encoding become mandatory only after an approved M7-or-later
subtask proves that standalone machine execution and disk boot are no longer
reachable from the default executable.

## Status

Governance only. M2 T1 S1 remains the next eligible inactive subtask.
