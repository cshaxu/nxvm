# M0 T7 S1 Owned DOS Profile Direction Review

## Result

The M0 direction fixed the intended supported COM model, `INT 21h` allowlist, error
results, fixed-memory boundary, in-memory fixture filesystem, deterministic
Console, probes, and escalation rule. MCB, MZ/EXEC, path expansion, host-drive
integration, and product UI remain outside M2.

## Status

This is a historical planning record only. M2 later defines the Machine and
host-service boundary; M4 must turn this direction into the final DOS ABI before
M5 implementation starts.
