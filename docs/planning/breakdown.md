# Canonical Breakdown

The canonical six-milestone roadmap is [../roadmap.md](../roadmap.md).

- M0: governance, source/import policy, probe laboratory, and architecture plan.
- M1: validate an NXVM-derived machine foundation.
- M2: implement the owned DOS backend.
- M3: add non-invasive Windows platform integration and `ntvdm run`.
- M4: research optional BYOB Microsoft NTVDM guest components.
- M5: research invasive Windows integration only.
- M6: research and select a Win16 route.

Tasks and subtasks add bounded scope and acceptance criteria under these fixed
milestones. Do not reorder milestones without an owner-approved direction
record.
