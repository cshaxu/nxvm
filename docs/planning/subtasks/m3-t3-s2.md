# M3 T3 S2: Create ntvdm64.dos_minimal Profile Shell

## Objective

Create a no-media `ntvdm64.dos_minimal` runtime session that composes the core
Machine with declared PIC, PIT, keyboard, and 80x25 text-display shells. It
must reset deterministically and expose input/IRQ/text snapshots through
project-owned APIs.

## Non-Goals

- Do not add BIOS, POST, ROM, disk boot, disk devices, DOS loader, DOS
  interrupts, host filesystem, graphics, product CLI, or platform display.
- Do not borrow legacy whole-PC globals or alter `src/nxvm-baseline/`.

## Files And ABI Surface

- `src/runtime/dos_minimal.h`, `src/runtime/dos_minimal.c`
- `tests/runtime/dos_minimal_profile_smoke.c`
- `CMakeLists.txt`, `CMakePresets.json`

The session owns a core Machine plus private runtime device state. PIC/PIT and
keyboard behavior use typed core port callbacks. A text snapshot is copied out
by value. The core remains unaware of DOS, text layout, or input policy.

## Verification

Build `m3-dos-minimal-profile-gcc` and run its smoke. It must print
`M3:T3:S2:DOS-MINIMAL-PROFILE:OK`, prove no-media inventory, deterministic
reset/PIT/keyboard-IRQ/text behavior, and preserve the M1 baseline build.

## Stop Conditions

Stop if a shell feature requires a DOS ABI decision, firmware, disk/BIOS
behavior, concrete platform access, or baseline global state.
