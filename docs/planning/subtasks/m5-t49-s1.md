# M5 T49 S1: VM Device File Naming

Status: active, not started.

## Objective

Rename VM-private machine device files from legacy `v*` filenames to canonical
owner names:

- `vm/machine/vcmos.*` to `vm/machine/cmos.*`.
- `vm/machine/vdebug.*` to `vm/machine/debug.*`.
- `vm/machine/vfdd.*` to `vm/machine/fdd.*`.
- `vm/machine/vfdc.*` to `vm/machine/fdc.*`.
- `vm/machine/vhdd.*` to `vm/machine/hdd.*`.
- `vm/machine/vhdc.*` to `vm/machine/hdc.*`.

## Scope

- Use `git mv` for each file pair.
- Repair direct includes, CMake source paths, tests, current documentation,
  and owner-local API names where they currently expose the old filename.
- Preserve all storage ownership, lifecycle order, media behavior, controller
  callbacks, debugger behavior, Console grammar, and boot/reset behavior.
- Complete T49 by producing `build/output/nxvm_0_5_0049.exe` after successful
  verification.

## Non-goals

- No VM device logic rewrite.
- No type-layout change.
- No removal of transitional retained aliases such as `vcmos`, `vfdd`, or
  `vdebug` unless every caller can be changed mechanically without behavior
  risk.
- No default-profile firmware rename, provider/interface split, multi-session,
  DOS, CLI, CPU instruction, or platform migration work.

## Verification

1. Configure and build the GCC CMake tree.
2. Run affected VM device authority smokes.
3. Run dependency-DAG/source-root checks.
4. Run retained Console smoke.
5. Copy and hash `build/output/nxvm_0_5_0049.exe`.

## Stop Conditions

Stop if the rename changes device lifecycle order, media transfer behavior,
debugger state, Console/debugger UX, boot fixture behavior, or requires a
non-mechanical implementation rewrite.
