# M5 T3 S2: Keyboard And Text Snapshot Contracts

## Objective

Add a bounded core keyboard event queue and copied text-display snapshot
contract. Platform-facing consumers receive copied state only; they cannot
retain a Machine pointer or mutate guest state.

## Non-Goals

No Win32 window, host input thread, BIOS keyboard service, DOS input, or QDX
baseline migration is in scope.

## Verification

Focused smoke covers FIFO order, overflow rejection, reset clearing, snapshot
copy isolation, dimensions, and canonical PC/AT reset-vector regression.
