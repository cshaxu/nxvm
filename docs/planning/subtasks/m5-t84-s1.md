# M5 T84 S1: Shared Device Ownership

Status: active.

## Objective

Move PIC, PIT, DMA, KBC, and VADP storage and guest-domain refresh/reset order
into `core_machine`; keep CMOS, media controllers, BIOS, and QDX as VM/profile
providers registered before configuration freeze.

## Gates

Pointer-identity and device-order smoke, BIOS/POST checks, Console/debugger,
FDD/HDD boot, and the three-second FDD prompt/display gate.
