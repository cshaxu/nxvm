# M5 T99 S1: Root Type Include Boundary

Status: complete.

## Objective

Replace every active `core/machine/vglobal.h` include with the root `type.h`
foundation and delete the forwarding header.

## Non-Goals

- Do not rename type aliases, functions, macros, or device/profile APIs.
- Do not change Console, debugger, boot, media, platform, or provider behavior.
- Do not modify `src/nxvm-baseline/` provenance sources.

## Baseline And Scope

Baseline: `d95b629` (`M5 T108 S1`). The active include callers are core-machine
headers plus VM machine/default-profile headers. The only removed file is
`src/core/machine/vglobal.h`.

## Verification

1. `rg -n 'core/machine/vglobal.h' src tests CMakeLists.txt` has no active hit.
2. `cmake --build --preset nxvm-current-gcc -j 4`
3. `cmake --build --preset nxvm-current-gates-gcc -j 4`
4. `nxvm-vm-dos-prompt-smoke D:\\fdd.img`
5. Pipe `help`, `device fdd insert D:\\fdd.img`, `info`, and `exit` into
   `build/output/nxvm_0_5_0099.exe`.

Stop if any include requires a new compatibility forwarding header, a GCC gate
fails, or retained Console/FDD behavior differs.

## Result

All 17 active callers now include `type.h` directly and the forwarding header
is deleted. Evidence is `docs/verification/m5-t99-s1-root-type-include.md`.
