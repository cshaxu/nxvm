# M5 T12 S10: Keyboard-State Producer Switch

## Objective

Route only retained `win32KeyboardMakeStatus()` through copied ingress requests
and apply those requests at the execution boundary, preserving direct fallback
on enqueue failure.

## Precondition

M5 T12 S9 has approved the canonical source-root move order. This switch uses
the selected `vm/platform` and `vm/machine` paths, not a superseded root.

## Non-Goals

Do not move Win32 leaf source, switch key-down/F9/display producers, alter
keyboard mapping, Console/window behavior, display modes, thread lifetime, or
debugger behavior.

## Verification

Add focused keyboard-state request and fallback tests; build the user-facing
target and focused dependents; run the finite CPU probe, FDD-backed execution
context lifecycle smoke, FDD/HDD reset-vector smoke, and retained no-media
Console/debugger interactions. No raw instruction recorder run is allowed.

## Stop Condition

Stop for owner approval before any user-visible behavior change or a second
producer switch.
