# M5 T8 S1: Map The Real Execution Migration

## Objective

Produce the code-level, provenance-backed migration map that moves the actual
NXVM full-PC execution path out of `src/nxvm-baseline/` and into the declared
module owners without changing the retained Console or debugger contract.

## Non-Goals

No simplified Console, no command grammar or output change, no DOS backend,
and no speculative device rewrite. This subtask does not claim that the shared
core runs a guest merely because a facade can be constructed.

## Required Output

Record each source unit currently reached by the artifact's execution loop,
its globals and APIs, destination owner, import/provenance requirement,
dependency break, focused regression, and a bounded migration order. Identify
the smallest first runnable slice and every user-visible compatibility gate.

## Verification

The map must trace `main -> console -> debug/machine -> device -> platform`
and every boot-path dependency for the M1 FDD/HDD fixtures. It must distinguish
code that is merely composed from code that executes guest instructions.

## Stop Condition

Stop and request owner approval before any proposed migration changes retained
Console commands, debugger grammar, output, or default workflow.
