# M5 T12 S5: Inactive Synchronized VM Request Transport

## Objective

Implement the adapter-owned, synchronized copied ingress/egress transport
defined by S4, with no retained producer or execution-loop consumer connected.

## Non-Goals

Do not switch Win32, QDX, firmware, or execution-loop callers. Do not move
Win32 leaf sources or alter Console/window behavior, keyboard mappings,
display modes, thread lifetime, or debugger behavior.

## Verification

Add focused concurrency-free ownership, FIFO, overflow, and teardown-state
tests; build the user-facing target and focused dependents; run the finite CPU
probe, FDD-backed execution-context lifecycle smoke, FDD/HDD reset-vector
smoke, and retained no-media Console/debugger interactions. No raw instruction
recorder run is allowed.

## Stop Condition

Stop for owner approval before connecting any retained producer or consumer.
