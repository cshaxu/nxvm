# M5 T50 S1: Default Profile BIOS File Naming

Status: active, not started.

## Objective

Rename the default-profile BIOS firmware file pair from the legacy VM-shaped
name to the canonical profile role name:

- `vm/profile/default_profile/firmware/vbios.*` to
  `vm/profile/default_profile/firmware/bios.*`.

## Scope

- Use `git mv`.
- Repair direct includes, CMake source paths, tests, current documentation,
  and owner-local header guards.
- Preserve BIOS/POST/IVT order, reset-vector behavior, QDX registration,
  fixture boot behavior, retained Console behavior, and debugger behavior.
- Complete T50 by producing `build/output/nxvm_0_5_0050.exe` after successful
  verification.

## Non-goals

- No QD firmware rename.
- No BIOS logic rewrite.
- No removal of the transitional retained `vbios` alias unless every caller can
  be changed mechanically without behavior risk.
- No DOS, CLI, CPU instruction, platform, or multi-session work.

## Verification

1. Configure and build the GCC CMake tree.
2. Run BIOS/default-profile/reset-vector affected smokes.
3. Run dependency-DAG/source-root checks.
4. Run retained Console smoke.
5. Copy and hash `build/output/nxvm_0_5_0050.exe`.

## Stop Conditions

Stop if the rename changes BIOS/POST order, IVT registration, reset vector,
QDX behavior, Console/debugger UX, boot fixture behavior, or requires a
non-mechanical implementation rewrite.
