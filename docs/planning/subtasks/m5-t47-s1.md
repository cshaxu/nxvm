# M5 T47 S1: Version Foundation Closure

Status: complete.

## Objective

Make `src/version.*` the sole source for NXVM product identity and build-time
data, replacing the hard-coded banner in `vm/main.c` without changing the
retained Console experience.

## Scope

- Add `src/version.h` and `src/version.c`.
- Route the existing NXVM task suffix through the version formatter.
- Add a focused version smoke and `nxvm-m5_t47.exe` artifact.

## Non-goals

- No version-number change, post-M9 DOS identity, CLI, Console grammar, or
  machine lifecycle change.

## Verification

1. Configure and build the GCC CMake tree.
2. Run `ntvdm64-version-smoke` and verify
   `M5:T47:S1:VERSION-FOUNDATION:OK`.
3. Run `nxvm-m5-t47.exe`, verify its retained task banner, then send `EXIT`.
4. Run dependency-DAG and retained Console smoke gates.

## Stop Conditions

Stop if the NXVM product text, `0.4.015d.m5t47` suffix format, Console input,
or startup flow changes.
