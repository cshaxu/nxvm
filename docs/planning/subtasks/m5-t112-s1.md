# M5 T112 S1: ISO C Type, Object, And Atomic Vocabulary

Status: complete.

## Objective

Replace active project uses of ISO C library types, objects, constants, and
atomics with the `STD_*` facade. The facade directly maps to the ISO C
operation, so atomic object representation and memory-order semantics remain
unchanged.

## Guardrails

- Keep the native ISO spellings only inside `type.*` facade definitions and
  implementations.
- Keep fixed-width `int*_t` and `uint*_t` types unchanged.
- Do not alter guest strings, device behavior, Console/debugger behavior, or
  execution scheduling.
- Preserve every explicit atomic operation and memory order exactly.

## Verification

Scan active source/tests outside `type.*`, build `nxvm_0_5_0112.exe`, run all
GCC gates, the FDD DOS-prompt smoke, and the retained Console script.
