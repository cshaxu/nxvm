# M5 T13 S5: Core Ownership-Cutover Design

## Objective

Turn the T13 S1 core-to-VM/VDM dependency inventory into independently
buildable source-move/refactor slices. Each slice must identify its owner,
minimal callback or data contract, direct callers, and exact retained NXVM
regression gates.

## Non-Goals

Do not change runtime logic, Console, debugger, boot/media behavior, keyboard
semantics, CPU semantics, or begin M6.

## Verification

Produce a bounded order that removes every production `core/* -> vm/*` or
`core/* -> vdm/*` include without moving product policy into core. Review the
order against the existing whole-PC regression matrix.

## Stop Condition

Stop before implementing any callback/interface whose lifecycle or behavior is
not fully specified.
