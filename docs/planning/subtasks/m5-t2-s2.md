# M5 T2 S2: Transitional PC/AT Builtin Profile Registration

## Objective

Register only `nxvm.machine.pc_at_builtin` and
`firmware.provider.pc_at_builtin`, resolve them through the T2 registry, and
use the retained full-PC adapter for the existing reset-vector evidence.

## Non-Goals

No firmware/ROM migration, extra profile, external-ROM loading, media policy
change, Console change, or guest behavior change.

## Verification

Registry composition smoke verifies canonical id/provider lookup and that the
retained adapter still reaches `F000:FFF0`. Existing full-PC profile smoke and
M1 baseline build remain green. T2 artifact is created only after S2 closes.
