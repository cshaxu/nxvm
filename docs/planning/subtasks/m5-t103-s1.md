# M5 T103 S1: VM Composition And Machine API Naming

Status: complete.

## Objective

Normalize VM composition lifecycle/block/CPU-probe APIs and VM HDC lifecycle
APIs to their `vm_composition_*` and `vm_machine_*` owners.

## Non-Goals

- Preserve full-PC provider initialization/reset/refresh/final ordering.
- Do not change Console, debugger, BIOS, boot, media, or QDX behavior.
- Do not retain compatibility aliases.

## Verification

Active source/tests must have none of the replaced names; build
`nxvm_0_5_0103.exe`, all GCC gates, FDD DOS prompt, and retained Console.

## Result

The VM lifecycle, block binding, HDC lifecycle, and CPU-probe surface now
use their source-owner prefixes without compatibility aliases. Evidence is
`docs/verification/m5-t103-s1-vm-composition-machine-api-naming.md`.
