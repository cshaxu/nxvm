# M5 T83 S1: Executor Storage Migration

Status: complete.

## Objective

Move the real CPU, decoder, RAM, and legacy port storage into one
`core_machine` instance without changing the retained NXVM Console, debugger,
or boot behavior.

## Migration Discipline

First remove the conflicting minimal bus symbols. Then migrate one storage
family at a time by preserving pointer identity, repairing direct callers, and
passing core and FDD/HDD gates before the next family. VM may retain borrowed
accessors during this task but must not allocate or own a second object.

## Gates

Core CPU/memory/port smokes, Console/debugger smoke, FDD/HDD boot, and a
pointer-identity test for every migrated storage family.
