# M5 T78 S1: Debug Target Facade Replacement Design

Status: active.

## Objective

Trace the retained core debugger UI's global target lookup and define an
explicit composition-owned target binding that preserves command grammar,
output, pause behavior, and Console workflow.

## Constraints

- The debugger UI remains shared core product code.
- Do not redesign session management or add product-facing session controls.
- Do not change NXVM Console commands, startup behavior, or debug output.
