# M6 T1 S1: Design The Windows Platform And CLI

## Objective

Produce the M6 Platform/CLI design, security matrix, and M7 implementation plan
from `docs/requirements/runtime-cli.md`.

## Entry Conditions

1. M5 has passed its bounded DOS vectors and snapshot.
2. No platform semantics remain implicit in the DOS module.

## Verification

Review the filesystem-containment threat model and Windows 7 through Windows 11
matrix; verify CLI errors, program mapping, lifecycle states, debugger grammar,
and input-routing cases have testable expected outcomes. Produce the complete
M7 Task/subtask breakdown, mapping each implementation task to approved
Platform/CLI decisions, security cases, and acceptance results; M7 cannot start
from a pre-written implementation task.

## Stop Conditions

Stop for an undocumented Windows mechanism, a containment algorithm without a
race-handling argument, or an unbounded graphics/device expansion.
