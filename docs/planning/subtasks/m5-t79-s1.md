# M5 T79 S1: Session Transport Ownership

Status: active.

## Objective

Design the combined T79--T80 migration map for keyboard, execution, wait,
display mailbox, and host-surface ownership. No runtime migration begins until
the map identifies every Console and window thread entry, its context, and its
FDD regression gate.

## Boundary

T79 must not claim removal of host-side global calls while Win32/Linux entry
points lack an explicit context. No copied machine state, altered Console
grammar, or changed boot/reset order is permitted. The failed uncommitted
session attempt was discarded after it caused the FDD gate to fault; T78 is the
required runtime baseline for this redesign.

## Completion

This design subtask closes with an approved Console/window migration table and
focused gates. The first runtime cutover subtask then owns the task artifact
and FDD DOS-prompt gate.
