# M3 T3 S1: Make nxvm.full_pc Explicit

## Objective

Create an explicit `nxvm.full_pc` composition descriptor and a single-session
NXVM baseline adapter that owns the retained BIOS/CMOS/DMA/FDC/FDD/HDC/HDD/VADP
activation path. The adapter exposes fixture insertion, reset-vector
observation, start/stop, and teardown without exposing baseline globals.

## Non-Goals

- Do not claim that the global M1 device graph is already a reusable core
  Machine instance.
- Do not change imported baseline source, guest media, BIOS behavior, DOS,
  final `nxvm.exe` CLI, or host integration.
- Do not add an unbounded execution loop to core; the retained full-PC run is
  driven only by a bounded test harness.

## Reference And Assets

- M1 snapshot: `6d6b7d70ab6ed83ab973d27aeea6db88f4e87e4f`.
- M1 fixture identities: `docs/fixtures/m1-local-images.md`.
- The owner-provided local `fdd.img` and `hdd.img` are read-only test inputs;
  they must never be copied or committed.

## Files And ABI Surface

- `src/runtime/profile.h`, `src/runtime/profile.c`
- `src/adapters/nxvm_baseline/full_pc_profile.h`
- `src/adapters/nxvm_baseline/full_pc_profile.c`
- `tests/adapters/nxvm_full_pc_profile_smoke.c`
- `CMakeLists.txt`, `CMakePresets.json`

The runtime descriptor names enabled devices. The adapter remains outside
`core`, permits at most one legacy session, and only uses the imported baseline
through explicit initialize/configure/reset/start/stop/finalize calls. Its
fixture inputs are borrowed strings and are valid only for configuration.

## Verification

Run:

```text
cmake --preset mingw-gcc-x64
cmake --build --preset m3-full-pc-profile-gcc
build/mingw-gcc-x64/nxvm-full-pc-profile-smoke.exe
cmake --build --preset m1-baseline-gcc
git diff --exit-code -- src/nxvm-baseline
rg -n "windows.h|win32|Win32|INT 21|ntvdm64 run|products/" src/core src/runtime tests/core
git diff --check
```

Expected markers:

- smoke prints `M3:T3:S1:FULL-PC-PROFILE:OK`;
- profile inventory declares M1 full-PC devices and excludes DOS-minimal;
- fixture insertion and reset expose `F000:FFF0` for both FDD and HDD setup;
- baseline target builds with no imported-source change.

## Stop Conditions

Stop and escalate if a fixture is missing or mismatched, baseline initialization
requires a product CLI decision, adapter code must expose global device state,
or the retained path needs a new BIOS/disk behavior.
