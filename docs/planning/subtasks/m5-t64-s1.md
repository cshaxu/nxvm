# M5 T64 S1: Core Machine Naming And Instance Design

Status: complete.

## Objective

Freeze the forward-looking `core/machine` naming rules and produce the
session-ownership design required before any retained live alias is replaced
with context-passing code.

## Scope

- Classify each core-machine family as private implementation, exposed
  interface, injected provider, or session-owned registry.
- Define the exact firmware registry/provider split and the corresponding
  block, keyboard, display, port, and trace patterns.
- Record every selected-session global family and its required migration end
  state.
- State the no-copy, freeze, lifecycle, dependency, and compatibility gates.

## Non-goals

- No C source, CMake, binary, provider callback, Console, debugger, boot,
  reset, media, or guest-behavior change.
- No DOS implementation, VDM CLI, multi-session delivery claim, or CPU
  instruction correctness work.

## Completion Gate

The design is cross-checked against the current `core/machine` and VM
composition sources, linked from the forward architecture authority, and
expanded into the bounded T65--T73 implementation sequence. T65 S1 is the
only active successor. This task produces no executable because it changes no
runnable path.

## Stop Conditions

Stop for owner review if a proposed naming rule requires a compatibility break,
requires a core-to-product dependency, needs duplicated machine state, or
cannot state a session owner and provider lifetime for a capability family.
