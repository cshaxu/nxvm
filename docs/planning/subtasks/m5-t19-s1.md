# M5 T19 S1: Display Snapshot Regression Repair

## Objective

Restore retained NXVM full-PC execution throughput after the display snapshot
provider regression introduced by `ff4cd24`.

## Scope

Preserve the provider and snapshot contracts, but stop before copying the text
buffer when neither the display buffer nor cursor changed. This restores the
pre-P7 refresh cost on unchanged guest instructions.

## Reference And Gates

The good baseline is `5878aa5` and the first bad commit is `ff4cd24`.
Build `nxvm-m5-t18`, run core/VM dependency gates, and verify the frozen FDD
fixture reaches the DOS prompt using the same startup procedure as the
historical T13 comparison.

## Stop Condition

Stop if the repair changes Console grammar, guest display output, or requires
new guest-media behavior.
