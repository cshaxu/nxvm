# M5 T188 S1: Core Profile Binding Capability

Replace default-profile firmware's permanent RAM/execution configuration
borrows with a core-created `core_machine_profile_binding`. Firmware resolves
current core-owned memory/execution through the binding; it stores no raw core
RAM or execution field.

## Verification

- GCC artifact
- BIOS/QDX authority and QDCGA gates
- FDD DOS-prompt regression
- source scan rejecting raw RAM/execution fields in default profile context
