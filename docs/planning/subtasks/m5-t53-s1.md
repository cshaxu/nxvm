# M5 T53 S1: vglobal Retirement Path

Status: complete.

## Objective

Decide and begin the `vglobal.h` retirement path by moving only already-owned
shared declarations to clearer headers.

## Scope

- Audit declarations still provided by `src/core/machine/vglobal.h`.
- Move or replace only declarations whose owner is already obvious, such as
  project-wide types already covered by `type.*` or owner-local constants.
- Keep compatibility includes where needed until all callers are migrated.
- Produce `build/output/nxvm_0_5_0053.exe` if runnable paths changed.

## Non-goals

- No behavior change, type-size change, ABI split, or broad portability rewrite.
- No removal of retained aliases that still protect NXVM compatibility.
- No DOS, CLI, CPU instruction, or multi-session work.

## Verification

1. Configure and build the GCC CMake tree. Passed.
2. Run focused smokes for affected declarations. Passed.
3. Run dependency-DAG and live-machine authority gates. Passed.
4. Run retained Console smoke. Passed.
5. Build, smoke, and hash `build/output/nxvm_0_5_0053.exe`. Passed.

## Result

- Retained NXVM numeric aliases, pointer helpers, bit/constant helpers, BCD
  helpers, and `ExecFun` now live in `src/type.h`.
- `src/core/machine/vglobal.h` remains as a transitional include for retained
  device code and no longer owns those declarations.
- Further removal of `vglobal.h` includes is deferred to follow-up naming or
  state-authority tasks so retained compatibility is not disturbed.
