# M5 T80 S6: Scoped Wait Provider

Status: active.

## Objective

Remove the lifecycle-global core wait binding. Each host thread enters the
wait provider scope for its owning VM run context before it can invoke a host
wait, while the core machine stays platform independent.

## Gates

Focused wait-scope isolation smoke, facade-ownership scan, Console/window
regressions, and the FDD DOS-prompt gate.
