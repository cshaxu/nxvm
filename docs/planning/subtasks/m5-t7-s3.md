# M5 T7 S3: Restore NXVM Console Compatibility

## Objective

Restore the original NXVM Console as the `nxvm-m5-t7` user-facing artifact and
reopen M5. Preserve its command grammar, output, default workflow, and hardware
debugger behavior exactly while the actual full-PC execution path is still
baseline-backed.

## Non-Goals

No new Console grammar, simplified replacement UI, DOS backend work, or runtime
migration occurs in this subtask.

## Verification

Build `m5-t7-nxvm-artifact-gcc`; scripted `help`, `info`, and `exit` checks
must retain the original Console output. An interactive `debug` entry/exit
check must enter the original `-` debugger prompt with no mounted image, return
to `Console>` after `q`, and exit zero.

## Stop Condition

Stop and request owner approval before changing any user-visible NXVM Console
command, debugger grammar, or output semantics.

## Result

Complete. The task artifact is the original full-PC Console target, not the
temporary product Console. See
`docs/verification/m5-t7-s3-console-compatibility.md`.
