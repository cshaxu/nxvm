# M5 T9 S2: Lift The Retained NXVM Console Source

## Objective

Move the original NXVM Console and hardware debugger source into
`src/product/vm`, and its assembler and disassembler into
`src/product/core/debug/xasm32`, while retaining their user-visible behavior.
`utils` remains in place for this source slice because it is the common bridge
for the yet-unmigrated device and platform sources. This is the first
execution-source migration, not a new Console.

## Non-Goals

Do not change command grammar, text, default workflow, debugger semantics, or
the temporary baseline-backed execution engine. Do not begin DOS work.

All M5 compatibility-gate rules in `docs/history/m5/planning/m5-execution-migration.md`
apply. Stop for explicit owner approval before any user-visible change.

## Verification

Build the task artifact; compare original `help` and `info` markers; run the
delayed `debug`, `q`, `exit` interaction with no mounted media; and prove the
final artifact compiles its Console/debugger sources from `src/product/vm` and
its assembler/disassembler sources from `src/product/core/debug/xasm32`, not
`src/nxvm-baseline`.

## Stop Condition

Stop and request owner approval before any visible Console or debugger change.
