# M5 T9 S2: Lift The Retained NXVM Console Source

## Objective

Move the original NXVM Console, hardware debugger, assembler/disassembler, and
their support code into `products/nxvm` while retaining their user-visible
behavior. This is the first execution-source migration, not a new Console.

## Non-Goals

Do not change command grammar, text, default workflow, debugger semantics, or
the temporary baseline-backed execution engine. Do not begin DOS work.

All M5 compatibility-gate rules in `docs/planning/m5-execution-migration.md`
apply. Stop for explicit owner approval before any user-visible change.

## Verification

Build the task artifact; compare original `help` and `info` markers; run the
delayed `debug`, `q`, `exit` interaction with no mounted media; and prove the
final artifact compiles the Console/debugger sources from `products/nxvm`, not
`src/nxvm-baseline`.

## Stop Condition

Stop and request owner approval before any visible Console or debugger change.
