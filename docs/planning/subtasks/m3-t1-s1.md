# M3 T1 S1: Define Shared Core V1

## Objective

Create the first project-owned shared-core contract skeleton using parity-first
module layout. The subtask defines module-local `src/core/*.h` contract headers,
minimal `src/core/*.c` implementations, CMake targets, and a compile/link smoke
test without moving NXVM baseline behavior.

## Non-Goals

- Do not move CPU, RAM, BIOS, POST, disk, display, keyboard, debugger, or
  platform behavior out of `src/nxvm-baseline/`.
- Do not implement DOS services, product CLI behavior, host filesystem access,
  or Win32 integration.
- Do not create a top-level `include/` tree.
- Do not create a runnable product artifact.

## Reference Baseline

- M1 baseline source snapshot:
  `6d6b7d70ab6ed83ab973d27aeea6db88f4e87e4f`.
- M2 Shared Core Architecture Requirements V2 plus M2 T1 S3 parity-first header
  correction.

## Files And ABI Surface

- `src/core/status.h`
- `src/core/profile.h`
- `src/core/machine.h`
- `src/core/machine.c`
- `tests/core/core_contract_smoke.c`
- `CMakeLists.txt`
- `CMakePresets.json`

The public contract must expose only C11 project types, opaque Machine handles,
status/stop enums, generic profile selection, finite run budget/result structs,
and create/reset/run/request-stop/destroy entry points. Product profile names
such as `nxvm.full_pc` and `ntvdm64.dos_minimal` remain runtime/product
composition decisions, not core enum names.

## Verification

Run:

```text
cmake --preset mingw-gcc-x64
cmake --build --preset m3-core-contract-gcc
build/mingw-gcc-x64/nxvm-core-contract-smoke.exe
rg -n "windows.h|win32|Win32|INT 21|ntvdm64 run|products/" src/core tests/core
git diff --check
```

Expected markers:

- smoke test prints `M3:T1:S1:CORE-CONTRACT:OK`;
- no forbidden dependency scan result appears;
- no `build/output` artifact is created.

## Stop Conditions

Stop if the contract needs a product CLI, Win32, firmware, or baseline device
type; if a source move is needed; or if the compile/link smoke cannot be kept
independent of `src/nxvm-baseline/`.
