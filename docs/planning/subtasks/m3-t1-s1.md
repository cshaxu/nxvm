# M3 T1 S1: Refactor The Machine To The M2 Contract

## Objective

Execute the M2-approved migration plan while preserving every declared M1
baseline scenario. Publish the versioned Machine/DOS contract required by M4.

## Entry Conditions

1. M1 has a pinned import, frozen baseline experiment record, and immutable
   snapshot.
2. M2 has approved the device decision table, ownership diagrams, contract, and
   per-step M1 regression plan.

## Expected Surface

- `src/machine/`, `src/platform/`, and `src/adapters/` own the approved split;
- baseline-only coupling is removed only after its designated regression passes;
- a versioned Machine/DOS C contract exposes execution, memory, interrupt,
  device-lifecycle, stop-reason, and trace-boundary services; and
- `tests/machine/` contains the M1-derived focused regression cases.

## Verification

- exact M1 FDD/HDD scenarios and their frozen checkpoints;
- focused contract, reset, interrupt, device, and stop-reason tests;
- no forbidden module dependency; and
- GCC warning inventory, `git diff --check`, snapshot, tracking, and evidence.

## Stop Conditions

Stop for a behavior change without an M1 regression, an interface addition that
requires a DOS service decision, or a host-platform policy entering `machine`.
