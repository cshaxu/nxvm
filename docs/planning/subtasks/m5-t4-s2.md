# M5 T4 S2: Builtin PC/AT Firmware Package

## Objective

Complete the bounded, project-owned PC/AT firmware package: deterministic ROM
and BDA reset image, CMOS reset defaults, and registered identities for POST
and the INT 10h, 13h, 16h, and 1Ah BIOS services.

## Non-Goals

This task does not execute guest instructions through the new core, emulate a
complete BIOS, add an external ROM, or expose a host handle. T7 wires the
package into the first-class whole-machine execution path.

## Verification

`nxvm-pc-at-firmware-smoke` verifies frozen ordered composition, vector lookup,
CMOS defaults, BDA/ROM bytes, and the `F000:FFF0` far-jump reset stub. Its
expected marker is `M5:T4:S2:PC-AT-FIRMWARE:OK`.

## Stop Condition

Stop and escalate if the package needs host I/O policy, a third-party ROM, or
an undocumented BIOS compatibility promise.
