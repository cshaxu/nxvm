# M5 T115 S1: Debugger Input Flush Capability

Status: complete.

## Objective

Replace every `fflush(stdin)` use with a core product debug input provider
bound by VM composition to an explicit platform capability. On Win32, flush
only an actual Console input handle; other platforms safely provide no input
flush until they define a native equivalent.

## Guardrails

- Core product code cannot depend on VM or Win32 headers.
- Do not alter debugger commands, prompts, or command parsing.
- Do not flush redirected input as if it were a Console.

## Verification

Run the no-`fflush(stdin)` source scan, build `nxvm_0_5_0115.exe`, all GCC
gates, the FDD DOS-prompt smoke, and the retained Console script.
