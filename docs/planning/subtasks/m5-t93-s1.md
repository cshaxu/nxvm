# M5 T93 S1: VM Composition Context Integration

Status: complete.

## Objective

Make VM composition own the lifetime of its machine, platform, debugger, and
Console contexts, preserving the retained NXVM Console and boot behavior.

## Gates

Two full VM sessions retain independent control, Console, debugger, and
presentation behavior; FDD/HDD and current GCC gates pass.

## Result

`vm_composition_live_machine` now owns debugger, Console, and Console-target
contexts beside its existing platform context. Product entry points borrow those
contexts; no entry-stack lifetime selects a VM session.
