# M5 T172 S1: Core-Owned Stopped RAM Reconfiguration

## Objective

Add the one core-owned operation that replaces RAM without reconstructing a
session or machine.

## Contract

- `core_machine_reconfigure_memory(machine, bytes)` accepts only a frozen,
  `STOPPED` machine and the configured core RAM range.
- It retains the existing `core_machine`, CPU, RAM object, port bus, PIC/PIT/
  DMA/KBC/VADP, mappings, and provider registrations.
- It replaces only the RAM backing allocation, then invokes the normal cold
  reset and provider reset once. RAM and guest/device state are reset.
- It rejects `INITIALIZED`, `RUNNING`, `PAUSED`, and `FAULTED` states and does
  not rebind providers or create a second machine.

## Evidence

`nxvm-core-machine-memory-reconfigure-smoke` must prove object identity,
provider-reset count, zeroed RAM, new installed size, and rejected non-stopped
calls. GCC, retained Console, and FDD DOS-prompt gates remain required.
