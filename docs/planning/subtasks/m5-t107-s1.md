# M5 T107 S1: Root Type Vocabulary And Closure

Status: complete.

## Objective

Replace root-owned `t_*` aliases and non-retained `type.h` macros with clear
`ntvdm64_type_*` vocabulary, while leaving module-owned `t_cpu`, `t_pic`,
and similar structures for their own module-owner migration.

## Boundaries

- Preserve the approved all-uppercase C-runtime wrappers exactly.
- Preserve behavior and bit widths; do not merge same-layout module structs.
- Treat standard-library facade migration from T108 as a separate follow-up.

## Verification

Record the root/module classification, run the active root-legacy scan, build
`nxvm_0_5_0107.exe`, all GCC gates, FDD DOS prompt, and retained Console.

## Result

Root type aliases and non-retained root macros now use `ntvdm64_type_*` and
`NTVDM64_TYPE_*`. Module-owned legacy structures remain explicitly outside
this root closure. Evidence is `docs/verification/m5-t107-s1-root-type-closure.md`.
