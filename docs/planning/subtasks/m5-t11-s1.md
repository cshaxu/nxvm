# M5 T11 S1: PIC Source Migration

## Objective

Move the original NXVM PIC source and header to `machine/core` by `git mv`.
Repair only direct includes and CMake ownership needed for that move.

## Non-Goals

Do not change PIC behavior, IRQ ordering, firmware, DMA, PIT, keyboard,
storage, platform behavior, Console text, or debugger behavior.

## Verification

Build the user-facing target and focused controller dependents; run the finite
CPU probe, FDD-backed execution-context lifecycle smoke, FDD/HDD reset-vector
smoke, and retained no-media Console/debugger interactions.

## Stop Condition

Stop for owner approval before any user-visible behavior changes.
