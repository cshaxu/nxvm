# M5 T21 S1: Trace Interface Rename

## Objective

Rename the core machine event-observer unit from `trace` to `trace_interface`
without changing event types, callback semantics, or runtime behavior.

## Scope And Gates

Use `git mv`, repair direct include and CMake paths, build `nxvm-m5-t21`, and
run dependency-DAG, trace/core-contract, and retained Console gates.

## Non-Goals

Do not change trace buffering, sink ownership, raw-recorder policy, or public
`nxvm_core_trace_*` symbols.
