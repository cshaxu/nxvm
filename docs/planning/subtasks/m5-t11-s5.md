# M5 T11 S5: VADP Source Migration

## Objective

Move the original NXVM VADP source and header to `machine/core` by `git mv`.
Repair only direct includes and CMake ownership required for the move.

## Non-Goals

Do not change QDX display state, Win32/Linux presentation, BIOS behavior,
Console text, or debugger behavior.

## Verification

Build the user-facing target and focused dependents; run the finite CPU probe,
FDD-backed execution-context lifecycle smoke, FDD/HDD reset-vector smoke, and
retained no-media Console/debugger interactions.

## Stop Condition

Stop for owner approval before any user-visible behavior changes.
