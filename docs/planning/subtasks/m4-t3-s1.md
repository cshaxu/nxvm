# M4 T3 S1: Define The Retained NXVM Console

## Objective

Specify the retained interactive NXVM Console, its command compatibility
surface, state transitions, presentation ownership, debugger boundary, and
artifact identity. The Console is the `nxvm.exe` product interface; it is not a
process CLI and does not inherit `ntvdm64 run` behavior.

## Non-Goals

- Do not implement the new Console or change baseline command behavior.
- Do not define ntvdm64 window/debug Console ownership, Ctrl+C, or drive
  policy; those belong to M8.
- Do not add DOS loading behavior.

## Reference And Evidence

- Baseline command grammar: `src/nxvm-baseline/console.c`.
- Baseline Win32 presentation: `src/nxvm-baseline/platform/win32/win32con.c`
  and `win32app.c`.
- M3 debug boundary: `src/core/debug.h`.

## Deliverables

- Console state and compatibility contract in
  `docs/history/m0-m4/firmware-nxvm.md`.
- `docs/tracking/M4-T3.md` and compact verification record.

## Verification

```text
rg -n "HELP|EXIT|INFO|DEBUG|RECORD|SET|DEVICE|START|RESET|STOP|RESUME" src/nxvm-baseline/console.c
rg -n "NXVM Console|Console State|No Process CLI" docs/history/m0-m4/firmware-nxvm.md
git diff --check
```

## Stop Conditions

Stop and escalate if retaining a command requires direct core mutation,
platform-thread guest-state access, ntvdm64 policy, or an unreviewed host API.
