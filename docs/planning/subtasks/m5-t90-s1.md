# M5 T90 S1: VM Platform Surface Contexts

Status: active.

## Objective

Move mutable Win32 Console/window rendering state into explicit surface
contexts, and bind Linux terminal use through the `core/platform` lease
contract. Audit the absent VDM platform against this contract without adding
speculative implementation.

## Non-Goals

No CLI, VDM renderer, display-policy change, or new host capability.

## Gates

Two Win32 contexts must retain independent frame generations/resources. Linux
must reject a second terminal owner deterministically. Preserve FDD display and
NXVM Console behavior.
