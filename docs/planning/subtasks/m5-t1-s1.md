# M5 T1 S1: CPU Capability Manifest And Baseline Microprobes

## Objective

Define the project-owned CPU capability manifest and run bounded baseline CPU
microprobes that produce normalized positive and invalid-opcode evidence.

## Non-Goals

No retained CPU instruction implementation changes, Bochs source or patch
import, Bochx bridge linkage, firmware migration, new machine profile, or
guest-media test is in scope.

## Surface

- `src/core/cpu_capability.*`: implementation-neutral capability and verdict
  manifest.
- `src/adapters/nxvm_baseline/cpu_probe.*`: baseline-only one-instruction
  harness and normalized capture.
- `tests/adapters/nxvm_baseline_cpu_probe_smoke.c`: positive, prefix, and
  invalid-opcode paths.

The adapter may access the retained global CPU only through its explicit
baseline boundary. `core` remains independent of baseline, firmware, product,
DOS, and platform headers.

## Verification

```text
cmake --preset mingw-gcc-x64
cmake --build --preset m5-cpu-probes-gcc
build/mingw-gcc-x64/nxvm-baseline-cpu-probe-smoke.exe
cmake --build --preset m5-t1-nxvm-artifact-gcc
build/output/nxvm-m5_t1.exe
git diff --check
git diff --exit-code -- src/nxvm-baseline
```

Expected marker: `M5:T1:S1:CPU-PROBES:OK`.

## Stop Conditions

Stop and escalate if a probe requires a protected guest image, a Bochs-derived
source change, or any claim beyond its executed instruction/fault matrix.
