# M5 T80 S3: Linux Thread Context

Status: active.

## Objective

Implement C3 from the T79 map. Shape the Linux Console thread entry points to
accept the same explicit VM run context used by the Win32 surfaces, without
adding a Linux-window product surface.

## Non-Goals

Do not change the verified Win32 paths, Linux Console behavior, display
mailbox, mode/handle ownership, or wait scope. Do not make a POSIX runtime
claim from this Windows workspace.

## Gates

1. Static ownership scan proves Linux thread entries receive an explicit
   context and do not call global execution/input transports.
2. GCC Windows build and retained Console/FDD gates remain green.
3. A POSIX owner later compiles and runs the matching focused regression.

## Stop Conditions

Stop for owner review on a required behavior change, copied guest state, an
extra execution loop, a Windows regression, or a Linux-specific API decision
outside the T79 map.
