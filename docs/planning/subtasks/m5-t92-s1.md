# M5 T92 S1: NXVM Console Context

Status: complete.

## Objective

Move retained NXVM Console parser, target, arguments, and exit state into one
caller-owned Console context without changing grammar, prompt, or commands.

## Gates

Two Console contexts must not cross-target. Preserve Console grammar/output,
debugger entry, FDD DOS prompt, and current GCC structural gates.

## Result

The retained Console's target, parser buffer, argument vector, and exit flag
are caller-owned `nxvm_product_console_context` fields. The only static state
is a thread-local pointer that scopes the current caller-owned context.
