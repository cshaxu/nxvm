# M5 T6 S1: Retained NXVM Console Command Adapter

## Objective

Map the retained NXVM Console command surface onto explicit product/runtime
operations without introducing a new process CLI. Preserve familiar whole-PC
Console behavior while identifying commands still owned by the baseline path.

## Non-Goals

No `ntvdm64 run`, window-mode control Console, host-drive policy, or direct
cross-thread guest mutation.

## Verification

Focused command-adapter tests cover help, invalid input, start/reset/stop/exit
state rules, and media configuration rejection after execution begins.

## Stop Condition

Stop if preserving a command requires unbounded UI input, an M8 host policy,
or a direct baseline-global interface outside an explicit adapter.
