# M5 T12 S7: First Retained Producer Switch Design

## Objective

Specify the smallest retained Win32 producer switch to the bound ingress
transport, including exact ordering, fallback, teardown, and regression gates.

## Non-Goals

Do not change runtime code, switch a producer, move a Win32 leaf, alter guest
state, or change Console/window, keyboard, display, or debugger behavior.

## Verification

Record the selected producer, event schema, execution-boundary consumer,
fallback and rollback rule, and focused retained behavior tests. No raw
instruction recorder run is allowed.

## Stop Condition

Stop before implementation of the producer switch; owner approval is required
for any user-visible behavior change.
