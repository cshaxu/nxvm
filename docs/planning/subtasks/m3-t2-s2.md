# M3 T2 S2: Add Neutral Trace Boundary

## Objective

Add a disabled-by-default Shared Core V1 trace sink for reset, run-boundary,
port, stop, and fault events. Events are copied into fixed-capacity core-owned
storage and delivered without exposing a mutable Machine pointer.

## Non-Goals

- Do not add a differential-reference adapter, ntvdmx64 integration, logging
  product, file output, platform thread, or debugger command.
- Do not make tracing required for execution or change machine results when no
  sink is installed.
- Do not emit DOS, firmware, host filesystem, or product CLI events.
- Do not change M1 baseline source or claim a trace comparison for it.

## Reference Baseline

- M2 trace contract in `docs/history/m0-m4/m2-machine-dos-architecture.md`.
- M3 T2 S1 lifecycle boundary at commit `8dffada`.
- M1 baseline snapshot `6d6b7d70ab6ed83ab973d27aeea6db88f4e87e4f`.

## Files And ABI Surface

- `src/core/trace.h`, `src/core/trace.c`, `src/core/machine_impl.h`
- `src/core/machine.h`, `src/core/machine.c`, `src/core/port.c`
- `tests/core/machine_trace_smoke.c`
- `CMakeLists.txt`, `CMakePresets.json`

The sink is owned by the caller and is installable only outside `running`.
Its callback receives an immutable event copy and an opaque caller-owned
context, never a Machine address. The core queue is fixed-capacity and drops
only trace records under recursive pressure; it never changes guest state or a
Machine stop reason.

## Verification

Run:

```text
cmake --preset mingw-gcc-x64
cmake --build --preset m3-machine-trace-gcc
build/mingw-gcc-x64/nxvm-core-machine-trace-smoke.exe
cmake --build --preset m3-machine-lifecycle-gcc
cmake --build --preset m1-baseline-gcc
rg -n "windows.h|win32|Win32|INT 21|ntvdm64 run|products/|nxvm-baseline" src/core tests/core
git diff --check
```

Expected markers:

- trace smoke prints `M3:T2:S2:TRACE:OK`;
- null-sink and disabled-sink Machine results are identical;
- recorded reset/port/run/stop/fault event order and fields are deterministic;
- M1 baseline builds without source modification.

## Stop Conditions

Stop and escalate if trace needs a platform callback, dynamic unbounded buffer,
external implementation, mutable Machine access, or changes a no-sink result.
