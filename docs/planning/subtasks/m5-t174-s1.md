# M5 T174 S1: RAM Cold-Reconfiguration Closure

## Objective

Close the T169--T173 RAM work with enforceable source-shape and retained
runtime evidence. Retire T165's whole-session reconstruction as historical
transition evidence only.

## Checks

The closure gate requires the core stopped-only operation and cold reset,
rejects old raw-address names and non-core backing access, and confirms the VM
route uses the core operation without finalizing a session. The full current
GCC gate suite, Console lifecycle, FDD DOS prompt, session reconfiguration
smoke, versioned artifact, and clean temporary build tree are required.

## Rules And Non-Goals

Applicable `RULES.md` invariants are single ownership, frozen provider
topology, no provider backing pointers, retained NXVM behavior, one active
subtask, artifact/version evidence, and build hygiene. This task adds no RAM
mapping, hardware hot reconfiguration, Console grammar, or VDM behavior.

## Stop Conditions

Stop on a modulo RAM fallback, raw provider pointer, whole-session rebuild,
unsupported hot-reconfiguration claim, or any retained gate failure.
