# M5 T118 S1: VM Session Convergence

Status: complete.

## Objective

Make `vm_session` the one real bootable-VM session object. It owns the core
machine, VM-only devices, selected default-profile bindings, platform/product
contexts, host request transport, and session control. It is the only real
NXVM execution path.

## Required Convergence

- Replace the former live-machine object with `vm_session`.
- Fold the small `full_pc` wrapper and its host request transport into that
  session; do not leave a second owner around the session.
- Delete `default_profile`, `full_pc_session`, and `session_model` wrappers.
  Their callers and smoke assertions must use `vm_session` directly.
- Keep profile implementation/assets under `vm/profile`; session chooses and
  binds a profile but does not duplicate it.
- Split control state from outer execution: `session_control` owns atomic
  stop/pause/reset/step state; `session_runner` owns host scheduling and calls
  `core_machine_run` only through the retained execution boundary.

## Guardrails

- Do not change NXVM Console grammar, debugger commands, boot flow, device
  behavior, or FDD DOS-prompt outcome.
- Keep exactly one authoritative core machine per `vm_session`; no second
  firmware/minimal machine may remain for a smoke-only path.
- Use `git mv` for source relocation/renaming and retain focused regression
  coverage for configuration, reset vector, media, Console, and two-session
  isolation.

## Completion

Produce `build/output/nxvm_0_5_0118.exe`, pass the GCC gates, FDD DOS-prompt
smoke, retained Console script, and remove disposable build trees.
