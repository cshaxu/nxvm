# M5 T5 S1: NXVM Media Policy And Block Provider

## Objective

Define and implement session-owned NXVM boot-media selection and immutable
block-provider identity. It accepts only local FDD/HDD image inputs, freezes
media configuration before execution, and exposes no M8 host-filesystem policy.

## Non-Goals

No host drive mapping, writable guest-media promise, third-party media,
ntvdm64 CLI behavior, or migration of the baseline FDC/HDC implementation.

## Verification

A focused smoke verifies missing-media rejection, FDD/HDD selection, immutable
configuration after freeze, and stable fixture identity metadata. The retained
full-PC adapter smoke remains the execution regression.

## Stop Condition

Stop and escalate if a required operation needs arbitrary host-path policy or
would modify a protected fixture.
