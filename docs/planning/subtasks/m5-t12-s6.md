# M5 T12 S6: Inactive Execution-Boundary Transport Binding

## Objective

Bind the adapter-owned transport to the retained VM execution command boundary
with no retained producer connected; prove that only the execution owner may
consume ingress requests.

## Non-Goals

Do not switch Win32/QDX/firmware callers, apply any request to guest state,
move leaf sources, or alter Console/window behavior, keyboard mappings,
display modes, thread lifetime, or debugger behavior.

## Verification

Add focused ownership/lifecycle tests; build the user-facing target and focused
dependents; run the finite CPU probe, FDD-backed execution-context lifecycle
smoke, FDD/HDD reset-vector smoke, and retained no-media Console/debugger
interactions. No raw instruction recorder run is allowed.

## Stop Condition

Stop for owner approval before a retained producer is connected or a request is
allowed to mutate guest state.
