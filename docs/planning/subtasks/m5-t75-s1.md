# M5 T75 S1: Residual Facade Inventory And Static Gate

Status: complete.

## Objective

Inventory every process-global facade on the retained NXVM product path and
add a static gate that rejects new production call sites before the T76--T81
owner-by-owner removals begin.

## Reference Baseline

`b4a6d13` (`M5 T74 S1 P2: define facade executor convergence`).

## Scope

- Record global facade storage, binders, production callers, owner, and
  replacement task in `docs/planning/m5-facade-inventory.md`.
- Add `tools/VerifyFacadeOwnership.ps1` and a CMake verification target.
- Add the current task artifact target `nxvm-0-5-0075` without changing the
  retained executable's runtime behavior.

## Non-Goals

- No removal or behavior change to keyboard, display, debug, platform, block,
  or host-window code.
- No executor convergence, DOS, CPU, multi-session product feature, or UI
  change.

## Verification

```text
powershell -NoProfile -ExecutionPolicy Bypass -File tools/VerifyFacadeOwnership.ps1 -RepositoryRoot .
cmake --preset mingw-gcc-x64
cmake --build --preset nxvm-current-gcc
cmake --build build/mingw-gcc-x64 --target verify-facade-ownership
```

Expected markers: `M5:T75:FACADE-OWNERSHIP:OK`, successful GCC build, and
`build/output/nxvm_0_5_0075.exe` with the retained NXVM banner `0.5.0075`.

Completed with GCC 16.1.0 on 2026-08-02. The CMake target and direct script
both emitted `M5:T75:FACADE-OWNERSHIP:OK`; the artifact size is 1,631,637
bytes and SHA-256 is
`<recorded in docs/verification/m5-t75-s1-facade-inventory.md>`.

## Stop Conditions

Stop if the inventory finds an uncategorized production facade, the static gate
requires source suppression rather than an ownership rule, or adding the
verification target changes retained NXVM runtime behavior.
