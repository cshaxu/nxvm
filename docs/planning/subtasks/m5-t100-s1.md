# M5 T100 S1: Root Type Helper API Naming

Status: complete.

## Objective

Rename `utilsLowerStr` and `utilsTrace*` in `type.*` and all active callers to
root-owned `ntvdm64_type_*` names.

## Non-Goals

- Preserve all uppercase C-runtime wrappers exactly as-is.
- Do not rename `t_utils_trace*` data types in this task.
- Do not change trace controls, Console/debugger grammar, execution, or media.

## Verification

1. The active-source scan has no `utilsLowerStr` or `utilsTrace*` symbol.
2. `cmake --build --preset nxvm-current-gcc -j 4`
3. `cmake --build --preset nxvm-current-gates-gcc -j 4`
4. FDD DOS-prompt and retained Console insert/info/exit checks using
   `build/output/nxvm_0_5_0100.exe`.

Stop on any trace/Console/debugger behavior regression or a required alias.

## Result

All active callers use the root-owned `ntvdm64_type_string_lower` and
`ntvdm64_type_trace_*` functions. Evidence is
`docs/verification/m5-t100-s1-root-type-helper-naming.md`.
