# M5 T113 S1: ISO C Header Ownership

Status: complete.

## Objective

Make `src/type.h` the sole active repository boundary for ISO C headers,
including `stdint.h`; remove the redundant non-standard `memory.h` include.
Platform SDK headers remain local to platform adapters and tests that exercise
them.

## Guardrails

- Do not change C library calls, declarations, or product behavior.
- Do not move or wrap platform SDK headers.
- `src/type.h` may directly include ISO C headers because it defines the
  facade; active source and tests must include `type.h` instead.

DOS-prompt smoke, and the retained Console script.
