# M5 T10 S4: Explicit PC/AT Execution Context

## Objective

Replace the temporary single-session binding around the moved NXVM execution
carrier with an explicit session-owned context and callback boundary, without
changing retained NXVM Console, debugger, media, boot, display, or input
behavior.

## Verification

Build the T10 target; run two sequential reset/probe sessions, bounded
stop/reset/resume checks, finite CPU probe, and retained no-media
Console/debugger regression.

## Stop Condition

Stop for owner approval before any user-visible behavior changes.
