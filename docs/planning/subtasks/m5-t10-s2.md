# M5 T10 S2: Move The Full-PC Lifecycle Carrier

## Objective

Move the original NXVM lifecycle and refresh-loop implementations in the first
small execution-carrier slice: `machine.c/.h`, `device.c/.h`, and
`vmachine.c/.h`. The user-facing NXVM target must compile the moved files;
the old tree may contain forwarding headers only while its dependent controllers
remain in place.

## Non-Goals

Do not move CPU, RAM, port, controller, firmware, or platform code. Do not
change the Console, debugger, display, input, media, boot, or thread behavior.
Do not add a second execution loop.

## Verification

Build the M5 T10 target; inspect its CMake source set; run no-media
`help`, `info`, `exit`, and delayed `debug`, `q`, `exit`; and run the existing
full-PC reset-vector smoke with its required local fixture arguments when they
are available. Record any fixture absence without substituting protected media.

## Stop Condition

Stop for explicit owner approval before any functional or user-visible change,
or if the exact original refresh order cannot be retained.
