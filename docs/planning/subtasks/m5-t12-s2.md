# M5 T12 S2: Win32 Dispatch Boundary Audit

## Objective

Map the original Win32 dispatch layer's direct guest-state calls and define the
smallest compatible input/display bridge required before source migration.

## Non-Goals

Do not move or rewrite Win32 source. Do not change Console/window selection,
keyboard behavior, display paint, thread lifetime, graphics modes, or debugger
behavior.

## Verification

Record direct `deviceConnect*` callers, their event or display purpose, a
bridge owner, and retained regression gates. No raw instruction recorder run is
allowed.

## Stop Condition

Stop before a source move would retain platform-thread mutation of guest state
or require a user-visible behavior change.
