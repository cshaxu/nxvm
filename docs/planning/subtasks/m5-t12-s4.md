# M5 T12 S4: Request-Bridge Activation Boundary Design

## Objective

Specify the one-way handoff from platform-owned copied requests to the VM
execution command boundary, without introducing a `machine -> platform`
dependency or switching any retained Win32 producer.

## Non-Goals

Do not change runtime code, activate the bridge, move Win32 leaf sources, alter
Console/window behavior, keyboard mappings, display modes, thread lifetime, or
debugger behavior.

## Verification

Record the bridge owner, queue ownership/lifetime, execution-boundary consumer,
request ordering and overflow behavior, teardown rule, and source locations for
the later focused tests. No raw instruction recorder run is allowed.

## Stop Condition

Stop before a design requires a platform thread to access mutable guest state,
or before any producer switch.
