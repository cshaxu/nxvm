# M5 T4 S1: Firmware V1 Service Registry

## Objective

Implement session-owned typed firmware-service registration, duplicate/vector
conflict rejection, order validation, freeze semantics, and deterministic
ordered enumeration.

## Non-Goals

No ROM bytes, POST, CMOS, BIOS interrupt implementation, host capability, or
baseline firmware migration.

## Verification

Focused smoke covers duplicate id, conflicting interrupt vector, invalid order,
freeze, and ordered service enumeration. The canonical PC/AT reset-vector smoke
remains green.
