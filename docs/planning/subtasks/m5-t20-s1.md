# M5 T20 S1: Keyboard Interface Rename

## Objective

Rename the shared core keyboard provider unit from `keyboard_state` to
`keyboard_interface` without changing its API or behavior.

## Scope And Gates

Use `git mv`, repair direct include and CMake paths, build `nxvm-m5-t20`, and
run dependency-DAG, core-contract, and retained Console startup/exit gates.

## Non-Goals

Do not rename provider symbols, request payload fields, or platform sink types.
