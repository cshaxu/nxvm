# M5 T72 S1: Product Runtime Authority

Status: active.

## Objective

Move retained NXVM Console, debugger, and product-runtime callers from the
selected execution-context facade to their composition-owned session target.
Preserve every command, debugger prompt, boot/reset sequence, and FDD boot
behavior.

## Scope

- Map each `core_machine_cpu_execution_current()` consumer and retained product
  alias.
- Thread the existing composition session/target through Console and debugger
  command dispatch without changing grammar or output.
- Remove T72-owned selected execution accessors only when no caller remains.

## Non-goals

No Console redesign, CLI work, debugger feature, multi-session UX, or DOS
implementation is introduced. T73 alone deletes the shared legacy selection
layer and proves two-session isolation.

## Required Evidence

- Product-source scan identifies no T72-owned selected execution lookup.
- Retained Console and debugger smokes pass.
- Full-authority and FDD three-second DOS-prompt gates pass.
- `build/output/nxvm_0_5_0072.exe` is produced only after those gates pass.

## Stop Conditions

Stop on a changed Console/debugger command, changed startup/reset order,
second machine state, or a failed fixture-backed DOS-prompt gate.
