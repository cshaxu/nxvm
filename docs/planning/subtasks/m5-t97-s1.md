# M5 T97 S1: VM Composition API Naming

Status: complete.

## Objective

Replace the active `vmachine*` lifecycle symbols with explicit
`vm_composition_providers_*` names and replace `devicePrintMachine` with
`vm_composition_print_machine`.

## Non-Goals

- Do not change initialization, refresh, reset, or finalization ordering.
- Do not change NXVM Console commands, debugger behavior, boot flow, or media
  behavior.
- Retain approved compact names: `kbc`, `vadp`, `win32app`, `win32con`,
  `linuxapp`, `linuxcon`, `w32a`, `w32p`, `xasm32`, `aasm`, `dasm`, and
  `debug`.
- Retain the QDX default-profile firmware hacks: `qdx`, `qdcga`, and
  `qdkeyb`.

## Baseline And Scope

Baseline: `2111ad4` (`M5 T96 S1`). Scope is `src/vm/composition.*` and its
direct callers, version artifact wiring, and this tracking record. Historical
provenance and verification records retain their original terminology.

## Verification

1. `cmake --build --preset nxvm-current-gcc -j 4`
2. `cmake --build --preset nxvm-current-gates-gcc -j 4`
3. `nxvm-vm-dos-prompt-smoke D:\\fdd.img`
4. Pipe `help`, `device fdd insert D:\\fdd.img`, `info`, and `exit` into
   `build/output/nxvm_0_5_0097.exe`.

Expected markers are the current gate markers, `M5:T70:S2:DOS-PROMPT:OK`,
and an `inserted` FDD line. Stop if a compiler error, Console behavior change,
or DOS prompt regression appears.

## Result

All active composition lifecycle calls now use the explicit composition API.
The full GCC gates, the FDD DOS-prompt smoke, and the retained Console script
passed. Evidence is `docs/verification/m5-t97-s1-composition-api-naming.md`.
