# M5 T71 S1: Profile Firmware Authority

Status: active.

## Objective

Move default-profile BIOS/QDX/CGA/keyboard/disk firmware consumers from the
selected live-machine facade to explicit composition-owned profile objects and
provider slots. Preserve POST, interrupt-registration order, boot/reset,
retained Console, and FDD DOS prompt behavior.

## Non-goals

No new firmware feature, ROM format, profile selection UX, Console grammar,
or DOS backend behavior is introduced.

## Required Evidence

- Map every `vbios`, QDX table/current accessor, and default-profile static
consumer before deletion.
- Each firmware callback receives its owner or a non-owning profile context.
- Default-profile, full-authority, Console, and fixture FDD start gates pass.
- The T71 artifact uses `0.5.0071` only after the source scan is clean.

## Stop Conditions

Stop if migrating an interrupt handler changes registration order, requires a
second machine state, changes retained Console behavior, or fails the FDD
insert/start survival gate.
