# M5 T7 S1: First-Class PC/AT Product Composition

## Objective

Make `nxvm.machine.pc_at_builtin` select a product-owned composition that owns
profile/provider registration, firmware package, media policy, Console command
adapter, presentation/debugger adapters, and a bounded retained full-PC
execution bridge for the M1 fixtures.

## Non-Goals

This is not a CPU rewrite or a claim that every retained baseline device has
already moved into `core`. The bridge remains explicit until equivalent shared
core device execution is proven.

## Verification

The product session smoke resolves the canonical registry profile/provider,
creates the package with FDD/HDD fixtures, verifies firmware and baseline reset
vectors, and verifies clean teardown. T7 S2 then performs cleanup and M5 close.

## Stop Condition

Stop if the composition bypasses the registry, hides a baseline global behind a
core interface, or cannot preserve both M1 fixture paths under bounded tests.
