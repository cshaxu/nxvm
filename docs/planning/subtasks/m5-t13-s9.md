> retained in the T14 migration inventory; do not implement this isolated plan.

## Objective

Replace `core/product/utils.c -> vm/platform/platform.h` with a core host-sleep
capability callback. VM product composition binds the retained platform sleep
provider before Console use and clears it on teardown; an unbound callback is
reported as unsupported.

Do not alter Console commands, sleep duration semantics, debugger timing,
platform threads, VDM behavior, or introduce a process-wide product selector.

## Verification

Build all targets; run the retained Console/debugger delay gate and CPU,
FDD lifecycle, and FDD/HDD reset-vector smokes. Confirm no `core/*` source
includes a VM platform header after the migration.

## Stop Condition

other user-visible timing behavior needs to change.
