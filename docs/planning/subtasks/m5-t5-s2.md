# M5 T5 S2: PC/AT Block Composition

## Objective

Connect frozen NXVM FDD/HDD block-provider descriptions to the retained full-PC
adapter through a product-owned PC/AT composition entry point. Preserve the M1
fixture reset-vector regression while making media selection explicit.

## Non-Goals

No arbitrary host filesystem mapping, write support, controller rewrite, DOS
backend behavior, or first-class shared-core execution replacement.

## Verification

The focused smoke takes local FDD/HDD fixture paths, configures and freezes
both slots, starts the product composition, and checks `F000:FFF0` for both
boot targets before clean teardown.

## Stop Condition

Stop if a fixture identity differs from M1, a baseline global has to leak into
the product API, or controller behavior needs a firmware/host policy decision.
