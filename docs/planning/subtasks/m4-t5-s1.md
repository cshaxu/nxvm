# M4 T5 S1: Generalize Profile And ROM Provider Design

## Objective

Supplement M4 with the versioned profile model required for future NXVM
machines and ntvdm64 execution environments. Define machine-profile and
execution-profile registries, firmware providers, user-supplied ROM manifests,
and the bounded M5 `pc_at_builtin` implementation path.

## Non-Goals

- Do not implement a second machine, external ROM loading, or a DOS profile.
- Do not import PCjs, PC110-emu, Award, Phoenix, or any ROM code or binary.
- Do not redistribute, download, mount, or validate a third-party ROM.

## Reference And Evidence

- M4 firmware contract: `docs/history/m0-m4/firmware-nxvm.md`.
- M3 profile adapter: `src/runtime/profile.c` and
  `src/adapters/nxvm_baseline/full_pc_profile.c`.
- ROM policy: `docs/source-policy.md`.

## Deliverables

- `docs/requirements/profiles.md`.
- Revised architecture, M2 context, M5 breakdown, tracking, and verification
  records.

## Verification

```text
rg -n "machine profile|execution profile|pc_at_builtin|external_rom_bundle" docs
rg -n "Award|Phoenix|PCjs|PC110" docs/requirements/profiles.md
git diff --check
```

## Stop Conditions

Stop and escalate if the supplement admits a protected ROM to the repository,
requires third-party code copying, creates a default external-ROM dependency,
or expands M5 beyond the one built-in PC/AT profile.
