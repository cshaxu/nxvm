# M5 T13 S6: Core Presentation-Type Cutover

## Objective

Move the shared text snapshot representation to `core/machine/presentation.h`
and remove the `core/platform/presentation.h -> vdm/machine/dos_minimal.h`
include. VDM presentation explicitly converts only characters and attributes
from its private DOS-minimal snapshot; PIT and keyboard-IRQ state remain VDM
machine-private and require a future VDM diagnostic contract if exposed.

## Non-Goals

Do not change text content, dimensions, input ordering, VDM behavior, VM
behavior, Console/debugger behavior, or introduce a host presentation provider.

## Verification

Build all targets and run the focused DOS-minimal presentation/profile smokes
plus retained CPU, FDD/HDD, Console, and debugger gates. Confirm no production
`core/*` source includes a VDM header through the presentation contract.

## Stop Condition

Stop for owner approval before a snapshot field, conversion, or visible text
behavior needs to change.
