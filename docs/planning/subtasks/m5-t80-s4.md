# M5 T80 S4: Presentation Mailbox

Status: active.

## Objective

Implement C4 from the T79 map. Replace the process-global core display-frame
mailbox with a VM presentation mailbox explicitly owned by the VM platform run
context and fed through composition.

## Non-Goals

Do not alter guest VADP/QDCGA state, renderer output format, Console/window
selection, mode/handle ownership, or wait scope. A mailbox must contain copied
presentation data only, never CPU, RAM, device, or profile state.

## Gates

1. Two-context mailbox isolation test.
2. Console and window presentation regression plus FDD DOS prompt.
3. No core-to-VM dependency and no remaining production caller of the old
   display-frame mailbox API.

## Stop Conditions

Stop for owner review on a copied guest object, renderer-format change, changed
display/boot behavior, cross-session overwrite, FDD failure, or a required C5
or C6 change.
