# M5 T189 S1: Product Banner Simplification

## Objective

Replace the runtime version object and formatter with the VM-owned
`PRODUCT_NAME` macro plus common compile-time banner macros in
`core/product/banner.h`. Keep the NXVM Console banner, blank lines, and prompt
order unchanged.

## Non-goals

- Do not change Console grammar, debugger behavior, boot flow, or window title.
- Do not introduce VDM runtime behavior.
- Do not create a version object, formatter function, or compatibility wrapper.

## Surface

- `vm/product/version.h` owns `PRODUCT_NAME`.
- `core/product/banner.h` owns `PRODUCT_VERSION`, `PRODUCT_COPYRIGHT`, and
  `PRODUCT_BUILD_TIME`, plus the printing macro.
- `CORE_PRODUCT_PRINT_BANNER()` emits the shared banner shape.
- Delete `src/version.*` and its obsolete smoke target.

## Applicable Rules And Evidence

- `RULES.md` product-form and abstraction rules: product identity stays at the
  product entry; the helper contains only common output.
- `RULES.md` file-ownership rule: the helper belongs in `core/product`.
- `RULES.md` governance rule: build the task artifact and preserve the Console
  prompt.

## Commands And Expected Results

1. Configure MinGW-w64 GCC with `mingw-gcc-x64`.
2. Build `nxvm-0-5-0189` and `nxvm-product-console-lifecycle-gate`.
3. Pipe `exit` to the artifact and confirm the exact identity line,
   copyright line, `Built on` line, and retained `Console>` prompt.

## Stop Conditions

Stop if the retained Console startup order, grammar, prompt, or artifact build
changes unexpectedly.
