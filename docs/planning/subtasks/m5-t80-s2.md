# M5 T80 S2: Window Run Context

Status: active.

## Objective

Implement C2 from the T79 map. Give the Win32 window procedure and its kernel
and display threads one explicit `GWLP_USERDATA`-owned run context, reusing the
T80 S1 live-machine transports without copying guest state.

## Non-Goals

Do not change Console C1 behavior, Linux, display-frame mailbox, mode/handle
ownership outside the window context, or wait-provider scope. Retain NXVM
Console commands, debugger grammar, window UX, reset/boot ordering, and guest
execution.

## Gates

1. GCC build with the focused transport tests.
2. Window launch, close, key-input, and FDD display regression.
3. Retained Console and FDD DOS-prompt gates.

## Stop Conditions

Stop for owner review on a changed window or Console interaction, copied guest
state, extra execution loop, changed boot/reset timing, failed FDD gate, or a
required C3--C6 change.
