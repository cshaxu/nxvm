# M5 T10 S3: Move CPU, RAM, Port, And Instruction Sources

## Objective

Move the original NXVM CPU, instruction dispatcher, RAM, port, and common
machine-state files to `src/machine/core` as one source-owned executor slice:
`vcpu.c/.h`, `vcpuins.c/.h`, `vram.c/.h`, `vport.c/.h`, and `vglobal.h`.
The moved implementation must remain the only implementation compiled by the
user-facing target.

## Non-Goals

Do not alter instruction semantics, CPU capability claims, debugger grammar,
Console/window behavior, controller behavior, firmware, DOS, or platform code.
Do not start raw instruction recording.

## Verification

Build `nxvm-m5-t10`; inspect its source set; run existing finite CPU probe and
one-instruction adapter probe; run reset-vector and no-media Console/debugger
checks. Any local FDD/HDD fixture run remains bounded and uses only recorded
local inputs.

## Stop Condition

Stop for explicit owner approval before any functional or user-visible change,
or if a temporary legacy-state binding cannot stay single-session and confined
to the execution thread.
