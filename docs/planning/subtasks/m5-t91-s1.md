# M5 T91 S1: Core Debugger Contexts

Status: active.

## Objective

Make parser, assembler, and disassembler workspaces caller-owned debugger
context state, while retaining the NXVM debugger command grammar and text.

## Non-Goals

No new debugger command, session manager, VM/VDM UI, or machine behavior
change.

## Gates

Two debugger contexts must not cross-target. Preserve retained Console/debugger
smokes, FDD DOS prompt, and the current GCC structural gates. Stop for owner
review if grammar, presentation, or debugger command timing changes.
