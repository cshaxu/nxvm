# M5 T81 S1: Residual Facade Closure

Status: complete.

## Objective

Delete only legacy facades proven to have no production caller, then close the
Story 1 ownership scan without changing NXVM Console, debugger, or FDD boot
behavior.

## Gates

Production-call-site inventory, facade-ownership scan, core/provider smokes,
Console/window regressions, and the FDD DOS-prompt gate.

Closure removes the dead global block, keyboard, display, display-frame,
platform input/execution, and Win32 keyboard-state facades. Explicit provider,
transport, mailbox, and run-context paths remain the only production routes.
