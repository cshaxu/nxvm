# M5 T32 S1: Core-Machine Interface Naming

## Objective

Make core-machine dependency boundaries explicit without changing guest,
Console, debugger, callback, reset, or execution behavior.

## Scope

- Rename public core-machine contracts to `*_interface.h`.
- Restore `core/machine/machine.h` as the private live-instance layout and
  internal helper header; move the public handle API to
  `machine_interface.h`.
- Normalize public machine symbols to `core_machine_*` and externally supplied
  callback aggregates to `*_provider`.
- Update callers, focused smokes, CMake artifact target, and architecture
  naming policy.

## Non-Goals

- No state migration, provider-lifetime change, callback-order change, or
  machine behavior change.
- No Console/debugger UX change and no CMOS/RTC work; that begins in T33.
- No project-wide root `STATUS`/`BOOL` type migration.

## Gates

Windows GCC build, core machine instance/lifecycle/debug/trace smokes,
dependency-DAG verification, retained Console/debugger smoke, and the runnable
`nxvm-m5_t32.exe` artifact. The established FDD prompt observation remains a
separate full-PC acceptance gate; this naming-only task must not weaken it.
