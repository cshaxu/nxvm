# M5 T111 S1: C Scalar Vocabulary

Status: complete.

## Objective

Replace project-owned uses of native C scalar keywords with the established
`C_*` typedef vocabulary. The native keywords remain only where `type.h`
defines those typedefs and in external SDK headers.

## Guardrails

- Keep fixed-width `int*_t` and `uint*_t` types unchanged.
- Preserve signatures, layout, casts, ABI, Console, debugger, and boot flow.
- Do not introduce Win32 aliases or change ISO C type/object usage; T112 owns
  those boundaries.

## Verification

Run a source scan outside the facade typedef definitions and baseline, build
`nxvm_0_5_0111.exe`, all GCC gates, the FDD DOS-prompt smoke, and retained
Console script.
