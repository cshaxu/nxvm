# M5 T110 S1: ISO C Call-Site Migration

Status: complete.

## Objective

Replace active direct ISO C calls outside `type.c` with the `STD_*` facade,
including allocation, memory/string, file, time, ctype, and formatting calls.

## Non-Goals

- Do not replace `fflush(stdin)` or alter debugger input semantics.
- Do not migrate scalar C aliases, direct ISO C headers, or Win32 vocabulary.

## Verification

Active source/tests outside `type.*` have no targeted direct ISO C function
calls. Build `nxvm_0_5_0110.exe`, all GCC gates, FDD DOS prompt, and retained
Console. The facade is a base CMake library, not a core-machine dependency, so
platform-only targets retain their module boundary.
