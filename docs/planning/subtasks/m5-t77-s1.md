# M5 T77 S1: Display Facade Replacement Design

Status: active.

## Objective

Trace QDCGA mode changes, composition display generation, snapshot capture,
and platform presentation. Define the smallest session/profile-owned context
that removes the old core display facade without changing retained host display
behavior.

## Constraints

- Do not copy or synchronize a second guest display state.
- Keep QDCGA firmware profile-owned and preserve core's provider contract.
- Do not merge platform ownership work from T80 into T77.
- Keep the existing FDD DOS-prompt and host-display gates.
