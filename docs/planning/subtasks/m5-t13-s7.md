# M5 T13 S7: Product Session Composition Cutover

## Objective

Remove VM/VDM selection from `core/product/runtime/session.*`. Move the
existing VM full-PC session composition to `vm/product` and create a separate
VDM composition owner, leaving core with product-neutral lifecycle/registry
contracts only.

## Non-Goals

Do not change profile selection behavior, DOS-minimal behavior, full-PC boot,
media, Console/debugger behavior, or create a VDM user-facing product.

## Verification

Define the exact replacement API and test migration before source edits. The
implementation must remove all `core/product/runtime/session.* -> vm|vdm`
includes, retain the existing session/profile smoke coverage, and pass the full
NXVM compatibility matrix.

## Stop Condition

Stop for owner approval before changing profile-selection semantics or adding
a shared core abstraction that still names VM/VDM profiles.
