# M5 T13 S8: Product Session Composition Split

## Objective

Implement the approved S7 split: remove static VM/VDM profile selection and
both product includes from `core/product/runtime`; move the existing full-PC
session pair to VM ownership; add the separate VDM minimal-session owner; and
move static profile descriptors to their product profiles.

## Non-Goals

Do not change profile names, device masks, reset behavior, FDD/HDD media
handling, DOS-minimal behavior, NXVM Console/debugger behavior, or create a
VDM user-facing executable.

## Verification

Build all targets; run distinct VM and VDM session/profile smokes; run the
finite CPU, FDD lifecycle, FDD/HDD reset-vector, Console, and debugger gates.
Confirm no production `core/*` source includes VM/VDM headers or names a
product profile ID.

## Stop Condition

Stop for owner approval before a profile name, descriptor value, reset result,
or user-visible NXVM behavior changes.
