# M5 T22 S1: Debugger Audit And Migration Design

## Objective

Audit the retained NXVM debugger and approve the T23 pause-boundary and T24
unified-backend design without changing runtime code.

## Result

`docs/planning/m5-debugger-migration.md` records actual ownership, target
state semantics, migration order, non-regression limits, and exit evidence.

## Non-Goals

Do not alter Console commands, execution scheduling, debugger behavior, or
create a task artifact. T23 remains inactive until this design is approved.
