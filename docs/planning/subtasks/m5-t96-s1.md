# M5 T96 S1: Console Lifecycle Regression

Status: complete.

## Result

T93 embedded the retained NXVM Console context in the live-machine session,
while the Console initialize callback still rebuilt that session. The rebuild
cleared the active Console context, so every non-`exit` command could fault.

Live-machine initialization is now single-lifetime and idempotent; the main
entry no longer finalizes a session already finalized by the retained Console
callback. A lifecycle gate feeds `help`, `info`, and `exit` through the real
Console and verifies teardown. Evidence is
`docs/verification/m5-t96-s1-console-lifecycle.md`.
