# M5 T9 S1: Normalize The Default Machine Profile Name

## Objective

Rename the current built-in machine-profile implementation from `pc_at` to
`default_profile`. The name expresses its role in the profile registry and
leaves room for future `pc110_profile` and other machine profiles.

## Non-Goals

Do not change machine behavior, profile composition, Console/debugger behavior,
or the temporary baseline-backed execution engine. Do not begin DOS work.

## Verification

Build the NXVM artifact and verify the renamed source, test, target, and public
symbol paths compile. Historical records may continue to use PC/AT when they
describe the actual emulated machine.

## Stop Condition

Complete. M5 T9 S2 owns the retained Console/debugger source migration.
