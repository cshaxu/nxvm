# M5 T11 S12: QDX Ownership Boundary Audit

## Objective

Map the original QDX source dependency edges and select the smallest safe
source-move sequence consistent with the `machine/core` and `platform` boundary.

## Non-Goals

Do not move, rewrite, split, or duplicate QDX source. Do not alter Console or
window presentation, keyboard input, video modes, BIOS behavior, or debugger
behavior.

## Verification

Record the source-edge map, forbidden `machine/core -> platform` edges, proposed
owners, direct consumers, and the required retained NXVM regressions. No raw
instruction recorder run is allowed.

## Stop Condition

Stop before any source migration whose destination would retain a concrete
platform dependency or require a user-visible behavior change.
