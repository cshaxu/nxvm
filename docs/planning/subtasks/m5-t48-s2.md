# M5 T48 S2: Core Device File Naming

Status: active, not started.

## Objective

Rename the low-risk shared core device files whose current names are verbose
or legacy-shaped:

- `core/machine/keyboard_controller.*` to `core/machine/kbc.*`.
- `core/machine/video_adapter.*` to `core/machine/vadp.*`.

## Scope

- Use `git mv` for each file pair.
- Repair direct includes, CMake source paths, tests, and current documentation
  references.
- Preserve all public behavior, state layout, provider callback order, and
  retained NXVM Console/debugger behavior.
- Complete T48 by producing `build/output/nxvm_0_5_0048.exe` after successful
  verification.

## Non-goals

- No KBC or video adapter logic rewrite.
- No provider/interface split.
- No VM-private `v*` device rename.
- No multi-session, DOS, CLI, CPU instruction, or platform migration work.

## Verification

1. Configure and build the GCC CMake tree.
2. Run focused KBC/VADP authority or dependent smokes.
3. Run dependency-DAG/source-root checks.
4. Run retained Console smoke.
5. Copy and hash `build/output/nxvm_0_5_0048.exe`.

## Stop Conditions

Stop if the rename changes lifecycle order, keyboard IRQ/state behavior,
display snapshot content, Console/debugger behavior, boot fixture behavior, or
requires a non-mechanical implementation rewrite.
