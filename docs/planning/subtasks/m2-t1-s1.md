# M2 T1 S1: Implement The Bounded DOS Profile

## Objective

Implement exactly the M2 profile in
`docs/requirements/m2-dos-backend.md` on the verified M1 machine contract.

## Non-Goals

Do not add an unlisted DOS function, dynamic MCB memory, MZ/EXEC, host
filesystem access, Win32 Console/window behavior, or graphics support.

## Entry Conditions

1. M1 has a verified machine contract and snapshot.
2. The M2 profile and its acceptance probes are unchanged or have an
   owner-approved amendment.
3. The DOS-to-machine and DOS-to-fixture-adapter interfaces are documented
   before implementation.

## Expected Surface

- `src/dos/` owns the COM loader, PSP, interrupt dispatcher, fixed-memory
  layout, handle table, fixture filesystem adapter, and deterministic Console.
- `src/machine/` exposes only abstract machine services required by DOS.
- `tests/dos/` owns the four acceptance probes and per-service regression tests.

## Verification

- focused M2 build and test commands defined with the implementation;
- the four acceptance probes in the M2 requirements document;
- `git diff --check` and updated evidence/tracking records.

## Stop Conditions

Stop for an unlisted service or behavior request. Preserve the evidence, then
route it according to the M2 stop rule rather than widening the implementation.
