# M5 T12 S8: Machine Directory Convergence

## Objective

Flatten `machine/core/contract` into `machine/core`, retarget all callers to
the colocated headers, and delete the obsolete `src/core` forwarding tree.
Keep `machine/vm` flat: its implementation and public headers remain direct
peers rather than an added interface layer.

## Non-Goals

Do not alter Win32 leaf source, keyboard mapping, Console/window behavior,
display modes, thread lifetime, startup flow, debugger behavior, or source
semantics. Do not add new code to `src/nxvm-baseline` or
`src/adapters/nxvm_baseline`.

## Verification

Use `git mv` for every moved source/header, update CMake and direct include
paths in each small batch, build the user-facing target and focused contract
smokes, then run the retained finite CPU, FDD/HDD reset-vector, Console, and
debugger gates. No raw instruction recorder run is allowed.

## Stop Condition

Stop for owner approval before any user-visible behavior change. The deferred
keyboard producer switch is M5 T12 S9, after this layout work closes.
