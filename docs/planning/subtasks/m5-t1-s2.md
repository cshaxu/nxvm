# M5 T1 S2: Optional Bochx/Bochs Experiment Harness

## Objective

Add an explicit default-OFF developer entry point for bounded Bochx/Bochs CPU
experiments using the owner-local Bochs 2.6 checkout. The project-owned part
must validate experiment metadata and produce a deterministic report envelope
without linking Bochs into a product executable.

## Non-Goals

No Bochs source, patch, firmware, media, binary, raw trace, or Bochs-derived
code is copied into this repository. No CPU repair, whole-machine comparison,
automatic Bochs build, default CMake target, profile claim, or product/runtime
dependency is included.

## Surface

- `tools/research/bochx/`: project-owned metadata validator and instructions.
- a default-OFF CMake option may expose only a developer utility target.
- local Bochs 2.6 and the historical NXVM Bochx patch remain external inputs,
  identified by path and hash in a local experiment manifest.

## Verification

```text
cmake --preset mingw-gcc-x64
cmake --build --preset m5-cpu-probes-gcc
cmake -S . -B build/bochx-research -G Ninja -DNTVDM64_ENABLE_BOCHX_RESEARCH=ON
cmake --build build/bochx-research --target ntvdm64-bochx-manifest-check
build/bochx-research/ntvdm64-bochx-manifest-check.exe <local-manifest>
git diff --check
```

Expected marker: `M5:T1:S2:BOCHX-MANIFEST:OK`. The manifest must not be
committed and must reference only local source and local patch identities.

## Stop Conditions

Stop and escalate for any request to import Bochs/patch material, to make the
reference bridge a default dependency, or to treat Bochs as an oracle beyond a
bounded CPU instruction/state experiment.
