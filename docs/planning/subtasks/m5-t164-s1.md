# M5 T164 S1: Core Configuration And Observation Boundary

## Objective

Replace generic mutable executor borrows with explicit configuration-only and
paused-debug access. Add one copied CPU/fault observation payload and enforce
the same returned-boundary rule for existing CPU/diagnostic reads.

## Scope

- Rename generic `core_machine_executor_*_borrow` and shared-device borrows to
  configuration-purpose APIs that reject non-`INITIALIZED` machines.
- Permit a registered VM/profile provider to retain a supplied child reference
  through core-controlled teardown, but do not expose it to Console commands.
- Add paused-only debug borrows for the retained composition debug adapter.
- Add a copied `core_machine_observation` API and lifecycle guards.
- Migrate current VM composition and core/VM test callers without changing
  provider order, Console grammar, boot timing, or debugger behavior.

## Non-Goals

No `DEVICE ram` reconstruction, media-policy change, provider redesign,
debugger grammar change, guest CPU change, or session-manager behavior change.

## Rules Review

- Machine/session: core remains the single child-state owner; borrowed pointers
  do not transfer lifecycle ownership.
- Interfaces/providers: configuration and paused-debug access name their
  boundary; product commands receive neither.
- Scope/testing: retain Console, debugger, FDD DOS prompt, multi-session, GCC,
  and no-forbidden-dependency gates. Produce `nxvm_0_5_0164.exe` only after
  runnable-path evidence passes.

## Verification

- Add core lifecycle/observation smoke coverage for configuration rejection,
  paused copied reads, and debug-access rejection while running.
- Run the current GCC preset, core lifecycle/observation smokes, Console and
  debugger gates, two-session isolation, and the FDD DOS-prompt gate.
- Remove the temporary build tree after artifact copy and verification.

## Stop Conditions

Stop for review if implementation requires a core-to-VM dependency, a mutable
raw core object exposed to a product/platform command, a second machine,
changed Console/debugger grammar, or an FDD/Console regression.
