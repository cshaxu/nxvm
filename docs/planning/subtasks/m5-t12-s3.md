# M5 T12 S3: Inactive VM Input And Display Bridge

## Objective

Add the smallest session-owned, copied-request bridge for Win32 keyboard state,
key press, stop, and display-mode requests without switching the retained
Console/window producers or changing observed NXVM behavior.

## Non-Goals

Do not move Win32 leaf sources, switch host event producers, remove direct
legacy calls, change Console/window behavior, change keyboard mappings,
graphics modes, thread lifetime, or debugger behavior.

## Verification

Add focused queue/request tests; build the user-facing target and focused
dependents; run the finite CPU probe, FDD-backed execution-context lifecycle
smoke, FDD/HDD reset-vector smoke, and retained no-media Console/debugger
interactions. No raw instruction recorder run is allowed.

## Stop Condition

Stop for owner approval before activating the bridge for host events or making
any user-visible behavior change.
