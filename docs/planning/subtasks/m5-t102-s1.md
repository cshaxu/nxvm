# M5 T102 S1: Core Product API Naming

Status: complete.

## Objective

Rename active shared-product APIs to `core_product_*`: debug entry, utility
wrappers, execution context, runtime registry, and runtime descriptors.

## Non-Goals

- Retain `debug`, `aasm`, `dasm`, and `xasm32` lexical names.
- Do not change debugger commands, assembler/disassembler behavior, runtime
  registry semantics, or session ownership.
- Do not retain compatibility aliases.

## Verification

1. Active source/tests have no `debugMain`, `utilsSleep`, `utilsAasm32`,
   `utilsDasm32`, `nxvm_execution_context`, or `nxvm_runtime_` API prefix.
2. Build `nxvm_0_5_0102.exe`, all GCC gates, FDD prompt, and retained Console.

Stop on debugger/registry behavior change, an alias requirement, or a retained
NXVM regression.

## Result

All active shared product debug/runtime APIs now use `core_product_*` names.
Evidence is `docs/verification/m5-t102-s1-core-product-api-naming.md`.
