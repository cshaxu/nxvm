# M5 T10 S5: User-Facing Carrier Source-Set Audit

## Objective

Prove that `nxvm-m5-t10.exe` compiles lifecycle, refresh loop, CPU, RAM, port,
and instruction dispatch from `machine/vm` and `machine/core`, not from
`nxvm-baseline` implementations.

## Non-Goals

Do not migrate controllers, firmware, storage, platform code, or product
Console behavior. Those remain T11 through T13 work.

## Verification

Inspect CMake's source lists and the generated build graph for the six migrated
implementation groups; build `nxvm-m5-t10`; run the S4 lifecycle, CPU, FDD/HDD
reset-vector, Console, and debugger gates.

## Stop Condition

Stop for owner approval before a user-visible Console, debugger, media, boot,
display, input, or threading behavior change.
