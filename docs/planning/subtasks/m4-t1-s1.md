# M4 T1 S1: Design The Bounded DOS Module

## Objective

Complete the M4 design gate in `docs/requirements/m5-dos-backend.md` as a full
ABI and vector specification.

## Entry Conditions

1. M3 has published its versioned Machine/DOS contract and snapshot.
2. M5 scope remains bounded to the approved profile.

## Verification

Every allowed DOS service has register/FLAGS, memory, error, and test-vector
definitions. The vector suite is reviewed against the M3 contract without
adding implementation code.

## Stop Conditions

Stop for unlisted DOS services, MZ/EXEC, dynamic MCB, host paths, or UI work.
