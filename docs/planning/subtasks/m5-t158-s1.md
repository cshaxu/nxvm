# M5 T158 S1: CPU And FPU Static Closure

## Objective

Close the M5 CPU/FPU profile sequence with a repeatable static census and
focused runtime gates.

## Scope

- Verify primary, `0F`, and FPU escape metadata provides a minimum CPU/FPU or
  explicit illegality for every form handled by the current decoder.
- Reject reintroduction of the historical unconditional `i386(n)` gate.
- Reject direct `D8`--`DF` dispatch to `UndefinedOpcode`.
- Preserve the default `80386+none` ESC/FWAIT behavior, session profile UX,
  Console/debugger, and FDD prompt evidence.

## Non-Goals

No present-FPU state/operations, protected-mode/paging completion, new CPU
forms, host integration, or user-interface redesign.

## Exit

A repository-owned static closure probe and current focused GCC gates pass;
the task produces `build/output/nxvm_0_5_0158.exe`. The closing evidence must
state that present FPU profiles remain unavailable.
