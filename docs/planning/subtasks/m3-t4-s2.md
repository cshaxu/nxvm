# M3 T4 S2: Move Developer Debugging Boundary

## Objective

Expose synchronized Machine debug commands for CPU state, memory inspection,
single-step, and continue. The provisional commands use finite run budgets and
never access retained baseline globals.

## Non-Goals

No final NXVM Console grammar, ntvdm64 debugger grammar, platform UI, thread
queue, disassembly engine, or breakpoint policy is introduced.

## Verification

The focused smoke must print `M3:T4:S2:DEBUG:OK`, demonstrate paused
read-register/read-memory/step/continue behavior, and source scans must find
no direct baseline global dependency.
