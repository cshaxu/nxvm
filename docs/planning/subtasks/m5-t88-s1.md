# M5 T88 S1: Machine Session-State Closure

Status: complete.

## Objective

Eliminate the remaining mutable file-static trace workspace in `core/machine`,
then replace `vm/machine` control and debug-instrumentation globals with an
explicit, synchronized session command/state boundary.

## Non-Goals

No session manager, new NXVM Console command, VDM run loop, or guest behavior
change. The execution thread remains the only writer of guest state.

## Planned Surface

- `src/core/machine/cpu_instructions.c` and its trace contract;
- `src/vm/composition_control.*`, `src/vm/composition_loop.c`, and VM debug
  instrumentation;
- focused two-context and concurrent command regressions.

## Gates

Build `nxvm-0-5-0088`; run the new trace-context and command-boundary tests,
the current GCC gate preset, and the retained FDD/HDD boot checks. Stop for
owner review if a fix changes Console/debugger grammar, guest timing, or reset
ordering.

## Result

The trace workspace is a context-owned heap object with idempotent finalization.
VM control fields are C11 atomics; reset requests are consumed only by the
execution loop. The trace-context, pause/step, FDD DOS-prompt, HDD-authority,
and GCC structural gates passed without a Console or boot-flow change.
