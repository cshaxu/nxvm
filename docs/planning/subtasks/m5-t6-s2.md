# M5 T6 S2: Presentation And Debugger Adapters

## Objective

Provide NXVM product adapters that pass queued input and copied text snapshots
at a command boundary, and expose the existing core paused-state debugger only
through its typed interface.

## Non-Goals

No platform window implementation, legacy global debugger calls, direct guest
memory access from a presentation thread, or new debugger feature claims.

## Verification

Focused tests prove FIFO input application, copied snapshot isolation,
paused-only CPU/memory/step/continue access, and rejection outside a command
boundary.

## Stop Condition

Stop if an adapter needs platform-thread guest mutation, a host-specific UI
rule, or a baseline-global device/debug interface.
