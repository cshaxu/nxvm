# M5 T68 S1: Core Device Instance Authority

Status: active.

## Objective

Move PIC, PIT, DMA, KBC, VADP, and core RAM A20 port-handler state to explicit
composition-owned device contexts. Each port callback receives its required
device and port reference through a typed registration; it may not select any
mutable state globally.

## Order

1. Replace the port callback table with typed handler/provider entries that
   carry an explicit owner reference while preserving port dispatch order.
2. Migrate RAM A20, KBC, PIC, PIT, DMA, and VADP one device at a time.
3. Preserve IRQ, DMA, display, and POST ordering; add same-object binding and
   two-context isolation checks after each device family.
4. Record VM-only and profile callbacks for T70/T71. T73 deletes forwarding
   aliases only after all callbacks are explicit.

## Stop Conditions

Stop on a copied device state, changed port width/latch semantics, changed
IRQ/DMA order, changed boot/reset/refresh order, Console/debugger regression,
or FDD DOS checkpoint failure.

## P1 Evidence

The port bus now has an explicit typed provider registration with `(t_port *,
owner)` arguments. Provider entries are sparse and owned by the port object,
so only migrated ports allocate storage; the legacy dispatch arrays retain
their original size as a temporary fallback. KBC status port `0x64` is the
first migrated provider and no longer reads `vport`. GCC and the VM port
authority smoke pass.

## P2 Evidence

The RAM A20 handler at port `0x92` now receives explicit RAM and port objects
from the typed provider registry; it no longer reads either selected alias.
GCC plus the RAM and port authority smokes pass. PIC, PIT, DMA, and VADP remain
separate migration slices because their handlers carry IRQ, timer, DMA, or
display ordering responsibilities.

## P3 Evidence

PIC command/data ports `0x20`, `0x21`, `0xa0`, and `0xa1` now bind typed
providers directly to their composition-owned master or slave state. The port
latch is passed to the existing ICW/OCW logic rather than selected globally.
IRQ arbitration, cascading, POST registration, reset, and refresh logic are
unchanged. GCC and the bounded PIC authority smoke pass.
