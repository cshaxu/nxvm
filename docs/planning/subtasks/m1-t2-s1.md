# M1 T2 S1: Import And Baseline The Full NXVM Machine

## Objective

After M1 T1 approves the GCC migration design, record and import the then-current
sibling NXVM `HEAD` into a temporary baseline area. Apply only the approved
build/compatibility changes, build with GCC, and reproduce current text-mode
FDD/HDD boot/execution behavior before subtractive changes.

## Entry Conditions

1. M1 T1 has an approved GCC migration design and Go decision.
2. Pin the assessed NXVM `HEAD`; create one provenance record per imported or
   substantially derived source unit, including a generated per-file manifest.
3. Reverify the read-only local fixture identities.

## Expected Surface

- `src/nxvm-baseline/` contains the complete imported baseline, including
  existing Win32 and Linux platform source, with no new product behavior.
- A project-owned compatibility header contains approved C11 portability shims;
  it does not bypass `_WIN32` or modify the sibling checkout.
- `tests/baseline/`, `THIRD_PARTY_NOTICES.md`, provenance, and fixture records
  capture the baseline evidence.
- After raw observation, only proven irrelevant Bochs bridge code and
  repository-only metadata may be removed; attribution and notices remain.

## Verification

- Run the GCC configuration/build commands frozen by M1 T1 and record warnings.
- Run FDD and HDD scenarios using the recorded Console commands; capture devices,
  checkpoints or stop reasons, display/trace markers, reached state, and
  instruction, wall-clock, and no-progress budgets.
- Classify `stop.com` and `reset.com` before use; their names do not define
  semantics or an M1 exit condition.
- A project-owned Console `load <host-binary-path>` command is out of the raw
  NXVM baseline. It may be designed only after M1 baseline evidence, and is not
  an M1 exit condition.
- Optional differential experiments require their own bounded record.

## Stop Conditions

Stop for a GCC failure outside the M1 T1 budget, behavior-affecting migration
patch, fixture mismatch, missing notices, or undocumented Windows dependency.
