# M5 T85 S1: NXVM Outer-Loop Cutover

Status: completed.

## Objective

Make the VM outer loop invoke bounded `core_machine_run()` quanta. Retain VM
ownership of host command boundaries, pause/reset/stop policy, display publish,
and scheduling. Delete `vmachineRefresh` and its independent instruction path.

## Gates

GCC build, core legacy-run smoke, full-PC FDD/HDD session smoke, three-second
FDD DOS-prompt/display gate, debugger target and pause/step boundary gates,
and the facade-ownership scan.

## Result

The VM loop now invokes `core_machine_run()` for every guest quantum. The
former VM instruction/reset loop and runtime `machine_refresh` callback are
deleted. Provider binding occurs from the one composition-control setup path,
so direct control users retain the same reset, pause, and step behavior.
