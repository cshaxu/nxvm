# M5 T178 S1: Direct Debugger Context Ownership

## Scope

Embed the core-product debugger command context directly in `vm_session`.
Retain the lazy `debug_target` allocation because it has its own explicit
creation and teardown boundary.

## Acceptance

- `vm_session` has one direct `debugger_context` member and no same-owner
  debugger-context alias.
- Console debugger entry passes the member address at the command boundary.
- Debug-target, unified debugger, and Console lifecycle gates retain behavior.

## Constraints

No debugger grammar, Console workflow, target lifetime, startup, or FDD
behavior changes are in scope.
