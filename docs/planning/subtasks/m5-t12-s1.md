# M5 T12 S1: VM Platform Hub Source Migration

## Objective

Move the original NXVM platform hub source and header to `platform/vm` by
`git mv`. Repair only direct includes and CMake ownership required for the
move.

## Non-Goals

Do not change Console/window selection, input, paint behavior, platform thread
lifetime, keyboard delivery, graphics modes, or debugger behavior. Do not move
Win32/Linux leaf providers in this subtask.

## Verification

Build the user-facing target and focused dependents; run the finite CPU probe,
FDD-backed execution-context lifecycle smoke, FDD/HDD reset-vector smoke, and
retained no-media Console/debugger interactions.

## Stop Condition

Stop for owner approval before any user-visible behavior changes.
