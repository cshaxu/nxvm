# M5 T2 S1: Profile And Firmware-Provider Registry

## Objective

Implement the versioned project-owned registry for NXVM machine profiles and
firmware providers, with duplicate, ABI, freeze, and capability-floor checks.

## Non-Goals

No external-ROM file loading, additional machine profile, ROM bytes, BIOS/POST
migration, host path, DOS policy, process CLI, or retained full-PC behavior
change is included.

## Verification

Focused registry smoke tests must cover ABI mismatch, duplicate ids, lookup,
provider/profile family mismatch, mutation after freeze, and a profile rejected
when its capability floor is not proven. The existing `nxvm.full_pc` adapter
must still reach its reset vector. T2 creates only its task-level artifact after
S2 completes.

## Stop Conditions

Stop and escalate if the registry needs concrete ROM bytes, an external path,
host API, or an additional machine profile to prove its contract.
