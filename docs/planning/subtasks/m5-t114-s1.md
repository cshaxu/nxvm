# M5 T114 S1: Win32 Adapter Vocabulary

Status: complete.

## Objective

Ensure public project declarations under `platform/win32` expose `C_VOID` and
`WIN32_*` types rather than raw Win32 SDK types. Keep the actual SDK calls,
callbacks, and private message-loop state inside adapter implementation files.

## Guardrails

- Retain approved `win32app`, `win32con`, and `w32*` lexical names.
- Do not wrap, rename, or alter Win32 SDK function calls.
- Do not affect Linux source or product behavior.
