# M5 T10 S1: Plan The Core Execution-Carrier Move

## Objective

Define the first small, independently buildable file-move slice for the actual
NXVM execution carrier: CPU refresh, machine refresh, memory, port dispatch,
and their required private state. The result must identify exact files,
includes, temporary bindings, and regression gates before implementation.

## Non-Goals

Do not move execution files, change the Console, alter boot behavior, or begin
DOS work. Do not make a lifecycle scaffold stand in for the real executor.

## Required Gate

The plan must preserve all M5 compatibility-gate behavior, retain a bounded
execution budget, and name the pre-move reset, no-media Console/debugger, and
fixture checkpoints. It must require explicit owner approval before any
functional or user-experience change.

## Stop Condition

Stop for owner approval if the intended file move cannot preserve the existing
NXVM functionality and Console/window experience.
