# M5 T3 S1: PIC, PIT, And DMA Core Device Contracts

## Objective

Introduce instance-owned generic PIC, PIT, and DMA contracts in `core` with
typed registration, deterministic reset/tick behavior, and focused IRQ/DRQ
tests. The retained PC/AT adapter remains the boot regression path.

## Non-Goals

No BIOS/POST migration, storage controller migration, keyboard/display work,
host callback, DOS behavior, or baseline source edit.

## Verification

Core smoke covers reset, IRQ priority/acknowledgement, deterministic PIT tick,
DMA channel request/acknowledgement, and duplicate registration rejection. The
canonical PC/AT reset-vector smoke remains green.
