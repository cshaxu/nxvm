# M1 T1 S1: Baseline The NXVM Machine Slice

## Objective

Import the smallest NXVM machine slice required to load and step a bounded
real-mode probe. Establish a project-owned C11 test harness around it.

## Non-Goals

Do not implement DOS services, change NXVM in place, import platform UI, add
Microsoft component research code, or establish a full boot path.

## Entry Conditions

1. Confirm the M0 GCC smoke record applies to the active checkout.
2. Pin the NXVM source revision and create one provenance record per imported
   or substantially derived source unit.
3. Document and test the imported slice's C11 portability boundary before
   adding device behavior. NXVM's MSVC-specific type spellings, including
   `unsigned __int64`, must be normalized in a project-owned compatibility
   header rather than bypassing `_WIN32` or modifying the sibling checkout.

## Expected Surface

- `src/machine/` receives only the selected imported machine units.
- `tests/machine/` receives host-independent instruction-step tests.
- `THIRD_PARTY_NOTICES.md` and the provenance record reflect the import.

## Verification

- compiler and probe smoke commands from `docs/build/toolchain.md`;
- focused C11 test command defined with the imported test target;
- a bounded real-mode probe proves expected registers, memory, and interrupt
  state.

## Stop Conditions

Stop and request direction if the selected NXVM slice requires unresolved
Windows UI, undocumented compiler assumptions, missing license notices, or a
larger device import than the M1 contract permits.
