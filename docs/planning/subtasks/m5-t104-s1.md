# M5 T104 S1: VM Platform API Naming

Status: complete.

## Objective

Normalize active VM platform hub, Linux, Win32, `win32app`, and `win32con`
APIs to `vm_platform_*` owner prefixes.

## Non-Goals

- Retain the approved `win32app`, `win32con`, `linuxapp`, `linuxcon`, and
  `w32*` lexical backend tags.
- Do not alter host input, window, Console, display, timing, or boot behavior.
- Do not retain compatibility aliases.

## Verification

Active source/tests must have none of the replaced unscoped platform APIs;
build `nxvm_0_5_0104.exe`, all GCC gates, FDD DOS prompt, and retained
Console.

## Result

All active VM platform APIs now carry `vm_platform_*` ownership prefixes;
approved backend lexical tags remain intact. Evidence is
`docs/verification/m5-t104-s1-vm-platform-api-naming.md`.
