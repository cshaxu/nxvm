# M5 T82 S1: Real Executor Contract

Status: complete.

## Objective

Define the one real `core_machine` executor contract and the bounded T83--T86
migration map before moving runtime code.

## Non-Goals

No storage move, CPU feature change, guest behavior change, DOS work, or
product UI change.

## Baseline

`b55956c` closes Story 1. The bootable baseline is
`build/output/nxvm_0_5_0081.exe` with the FDD DOS-prompt gate.

## Gates

The contract names every current executor owner, its target owner, lifecycle
order, provider edge, deletion task, and regression. It preserves one
synchronous `core_machine_run()` path and prohibits copied guest state,
core-to-VM dependencies, or a changed Console/debugger contract.
