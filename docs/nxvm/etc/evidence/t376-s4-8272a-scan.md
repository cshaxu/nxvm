# T376 S4: 8272A Scan Command Path

`M5:T376:S4:8272A-SCAN:OK`

## Contract And Owner

NEC's [uPD765 application note](https://www.bitsavers.org/components/nec/_dataSheets/uPD765_App_Note_Mar79.pdf)
lists Scan Equal (`11h`), Scan Low or Equal (`19h`) and Scan High or Equal
(`1Dh`) as nine-byte commands. Their execution phase compares FDD data with
main-system data, then reports ST0--ST2 and CHRN. The primary source does not
define the implementation's byte-wise comparison/wildcard detail; the
owner-authorized secondary [86Box FDC source](https://github.com/86Box/86Box/blob/master/src/floppy/fdc.c)
was consulted only for that controller behavior: `FFh` is no-care, Low-or-Equal
tests guest byte <= media byte, High-or-Equal tests guest byte >= media byte,
and the `SK` bit skips Deleted-Data sectors.

`core_machine_fdc` remains the sole owner. It adds one execution phase that
uses the retained host-to-controller DMA2 and non-DMA `3F5h` direction, media
read/provider mark callbacks, result/IRQ6 completion, 500-kbit/s byte gates,
and DOR cancellation. It creates no media format, host path, test-only API or
second DMA path. A satisfying sector completes with ST2 Scan Equal Hit (`04h`);
the selected EOT range without a satisfying sector completes with Scan Not
Satisfied (`08h`). Scan never writes the raw payload.

For a marked sector, the controller obtains the mark only through the frozen
provider. Without `SK`, Deleted-Data sets the existing ST2 Control Mark (`40h`)
while comparison continues. With `SK`, the controller advances over that sector
without requesting guest comparison bytes; exhausting the selected range then
reports Scan Not Satisfied without Control Mark.
