## Ownership And Design Constraints

CPU retains the sole selector, bus FIFO, decoder and repeat lifetime. Core
retains the sole pending completion, qualification key and guest timeline.
Copying completed instruction facts across decoder reuse is observation
lifetime, not a second architectural CPU/cache snapshot or execution path.
Private helpers may own real checked aggregation or stable data preparation,
not forward another identical public operation.

The current public origin enumeration has no accurate generic 486 source/L2
pair. The owner's standing timing-accuracy upgrade permission covers append-only
source identifiers and justified formula-input bits, preserving all existing
numeric values and structure layouts. Do not misuse an arithmetic-only or
control-only origin for bus/cache models. Any newly required public function,
type or layout expansion remains an explicit review stop.

Do not guess a large finite maximum for unbounded admitted provider latency.
The existing pending owner must transport accepted variable service without
executing another instruction, overstepping a caller budget or publishing a
retirement twice. A partial elapsed interval is not a retired instruction or
an automatically qualified physical duration. Preview never mutates live
state or supplies guest time. The four older-family contracts remain real
retained variants, not an excuse for a duplicate SX executor.
