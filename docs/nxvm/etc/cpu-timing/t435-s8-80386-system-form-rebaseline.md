# T435 S8 - 80386DX System-Form Rebaseline

The former ledger collapsed source-distinct system forms. This correction
records `LAR/LSL` register/memory and 16/32-bit forms, descriptor-table
memory 16/32-bit forms, and every legal special-MOV direction/register timing
row. The direct source is `I386DX-PRM-1990`, Chapter 17, including printed
pp. 17-115--17-116 for CR/DR/TR moves. It raises the 80386DX denominator from
427 base plus 953 contexts to 444 plus 977 (1,421 canonical keys). All added
forms are L3 and remain nonconforming until the later implementation publishes
their required path/formula inputs.
