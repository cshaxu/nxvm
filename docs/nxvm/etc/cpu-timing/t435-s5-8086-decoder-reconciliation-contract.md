# T435 S5 - 8086 Decoder Reconciliation Contract

## Purpose and completion predicate

This is the S5 input contract for comparing the current decoder with the S1
manual ledger and S2 manifest.  It is not a substitute timing authority.  A
direct form is closed only when it maps to an S1 rule, one or more S2 keys,
real Core functional proof, and a classified retirement result.  Prefix bytes
never constitute a standalone retirement.

The current lexical decoder admits 233 primary-byte candidates: 227 direct
8086 instruction bytes and six segment/repeat prefix bytes.  `LOCK` is a
seventh prefix byte whose legality is semantic, so the lexical preview
intentionally rejects it without a target.  The direct universe excludes
`60`--`6F`, `C0`, `C1`, `C8`, `C9`, `D6`, and `F1`; they are later-CPU or
invalid forms for this profile.

The decoder also rejects invalid ModRM extensions before semantic execution:
Group-2 `D0`--`D3 /6`; `MOV r/m16,Sreg` (`8C`) `/6`--`/7`; and `MOV
Sreg,r/m16` (`8E`) `/1`, `/6`, `/7`. `8C` and `8E` `/4`--`/5` are 80386
FS/GS forms, hence not 8086 forms. These are fault boundaries, not timing keys.
After those profile/form gates, the current lexical input has 57,926 accepted
opcode/ModRM byte-layout candidates. This is a decoder-scan sentinel, not a
manual instruction-form denominator: no-ModRM instructions intentionally occur
once per filler byte in this scan.

## Context partition

`26`, `2E`, `36`, and `3E` select the S1 +2 segment term only for a legal
memory source. `F0` selects the +2 LOCK term for every following 8086
instruction: the Intel 1979 manual describes it as a one-byte prefix holding
the bus LOCK signal while the following instruction executes, and the Intel
ASM86 guide explicitly permits it before any instruction. The memory-RMW-only
whitelist is later-80386 behavior and must not be used for this profile. `F2`
and `F3` select only the S1 repeat families. Odd-addressed word transfers
select the S1 +4 term only where the manifest's context contract permits it.

## Current reconciliation result

The contract exposed three omissions from the former frozen S4 universe:
`D7/XLAT`, `0F/POP CS`, and the former RMW-only LOCK context universe. All
three now have S1 entries, S2 keys, semantic tests, classified actual results
and owner-local timing rules. The LOCK expansion covers every successful
direct form and every legal segment/odd-word/repeat intersection generated by
the S2 contract. `Verify-8086DecoderLedger.ps1` compares the complete 1,053
canonical S1/S2 keys with the runtime result set, rejects duplicates or either
direction of difference, and rejects an unclassified or non-S1-backed result.
