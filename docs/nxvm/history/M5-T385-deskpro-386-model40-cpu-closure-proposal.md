# DeskPro 386 Model 40 80386 CPU Closure

## Purpose

Close the 80386 CPU, paging, protection, delivery and successful-retirement
ledger for the already selected 1986 original Compaq DeskPro 386 Model 40
(DeskPro 386/16). This follows the Model-40 profile/capability audit and is the
second of five bounded DeskPro candidates; it does not allocate device
functional work or board bus/service timing.

## Required scope

Consume the documented Model-40 model/revision, 16 MHz 80386, chipset, RAM,
ROM-slot boundary, display/storage selection and project-owned corpus. Build
the source-labelled 80386 form/state matrix for the selected CPU: 32-bit
width, paging, VM86, privilege, exception/interrupt delivery and system state
only where each is required by the selected profile or corpus.  Reconcile all
remaining 80386 source rows through the shared four-profile program, preserving
each 16-/32-bit architectural layout and one retirement publisher.

## Non-goals and stop conditions

No device functional repair, board wait state, ISA/DMA arbitration,
PIC/PIT/RTC/KBC/display/storage service timing, NMI route, physical clock or
Windows claim. Stop if the exact machine/corpus cannot make a CPU state
distinction observable; transfer it to the source ledger rather than infer it
from a generic 386 PC.

## Evidence standard

Require exact Model-40 provenance, CPU source/form/state ledger, caller and
publication sweep, focused paging/delivery/timing proof, retained earlier-CPU
regressions and an explicit handoff to the Model-40 device-functional
candidate.
