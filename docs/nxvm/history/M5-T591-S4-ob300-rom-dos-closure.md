The coordinator reviewed S1–S4 and accepted the original-ROM Machine
stage. Both Release host widths reach interactive ROM DOS through the
production worker, retain a file written by the guest, and list both
the writable C volume and the immutable D System Card. The new worker
generations after reset/resume and stop/start are verified in S3.

250 ms, and both pause within one second.

[Controlled baseline](../etc/evidence/t591-s4-ob300-dos-baseline.md).

work transfers to the [performance receiver](../proposals/m5-ob300-performance.md).
The [product receiver](M5-T592-ob300-product-qualification-proposal.md)
takes the exact original-ROM configuration, desktop verification and
the executable release. Windows remains in its own planned receiver.
This closeout changes only governance and evidence. The published
Shared receiving EXEs remain current.
