# M5 T497 IBM 5170 Native Floppy Contract Completion

| Subtask | Accepted result |
| --- | --- |
| S1--S3 | Primary IBM source, complete drive/media List 1 and current-code List 2 freeze the original 1.2-MB factory drive and 360-KB compatibility boundary. |
| S4 | One typed session-media path corrects Model 339 CMOS to type `02h`, defaults to 1.2 MB, admits 360 KB, and rejects 720 KB/1.44 MB. |
| S5 | A Model 339 360-KB DOS 5 replay reaches installer-ready after the profile declares the unpopulated monochrome aperture through the existing Core absent-memory owner. |

The retained [proposal](../proposals/m5-ibm-5170-native-floppy-contract.md)
defines this task's machine/drive boundary. T497 does not claim a 286-era
1.2-MB DOS replay without an appropriate owner-supplied image; that external
input belongs to the later four-profile supported-media matrix. It adds no
BIOS, FDC, image-guessing or parallel media path.
