# M5 T401: Four-Profile CPU Instruction-Correctness Audit

## Task Record

T401 is the owner-authorized four-profile audit of the selected 8086, 80186,
80286 and 80386 CPU semantic surface and its source-timing dispositions. It
uses Intel manuals as semantic authority and permits reference implementations
only as bounded secondary cross-checks. It does not establish physical CPU,
board or DeskPro Model-L3 timing.

## S1--S75 Audit And Timing Dispositions

The [audit ledger](../etc/evidence/t401-s1-four-profile-cpu-audit-ledger.md)
freezes the decoder universe, records the family/form audits and captures each
bounded repair. S75 completes the successful-retirement timing disposition:
authoritative source rows remain at their existing owners, while every other
successful selected form produces an explicit nonphysical observation and is
rejected from physical elapsed/timeline publication.

## S76--S78 Independent Closure

S76 correctly kept T401 open until a concrete decoded-form matrix existed.
S77 supplies that [matrix](../etc/evidence/t401-s77-concrete-form-requirement-matrix.md)
for the complete frozen primary, secondary, prefix and FPU/WAIT space. The

unsupported extensions, physical instruction cycles, bus and DeskPro board,
