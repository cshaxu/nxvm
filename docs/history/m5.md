recorded only in [Project Status](../planning/status.md). This document

task priority.

## Retained Baseline

The latest completed M5 technical baseline is **T263**. The current GCC
gate and artifact target select `vm-0-5-0263`; static/ownership checks and
99/99 CTest cases passed. The associated developer artifact is
`build/output/nxvm_0_5_0263.exe`, SHA-256
`CDECA028180652317C2EDC9C872B8BDB0F49A5465C506A6921BC2A00DB0CAF02`.
Artifact identity follows the task number: T263 is `0.5.0263`.

M5 preserves the runnable NXVM path while moving its verified machine
foundation under `core/` and `vm/`. The future `mantle`, `dos`, and `vdm`
components are not part of the M5 runtime build graph.

## Completed Work

- **T208--T216:** made the default PC/AT profile declarative; retired firmware
  portals; established ATA PIO, fault outcomes, and core PIC-owned IRQ
  delivery while preserving retained boot, Console, and debugger behavior.
- **T217--T227:** established deterministic elapsed-time scheduling, PIT and
  keyboard-controller behavior, and bounded CPU/host-input regression probes.
- **T228--T242:** added bounded CGA/EGA presentation, AUX mouse, DMA/FDC,
  CMOS/RTC, ATA, and system-image corpus coverage through project-owned probes
  and the retained full-PC regression matrix.
- **T243--T247:** established checked physical-memory routing, frozen
  undefined-instruction transitions, immutable ROM mappings, atomic entry
  plans, and the corrected full artifact/gate selection.
- **T248--T252:** admitted copied input, presentation, and cancellable-wait
  boundaries, then consolidated the sole VM composition lifecycle without
  changing retained product behavior.
- **T253:** extended the VM-owned ATA PIO controller through one admitted
  multi-sector task-file progress contract, with port and owner-built DOS
  round-trip coverage.
- **T254:** admitted the VADP-owned digital `640x200x2` CGA slice, default-ROM
  mode `06h`, and a boot-image regression that returns to text mode through
  normal video ports.
- **T255--T256:** froze the machine-profile admission contract, then replaced
  the PIT-only divider with per-machine integer rational clock domains for DMA,
  PIT, VADP, KBC, and frozen VM providers. This is Level 1 relative device
  timing, not instruction-, bus-, or cycle-exact emulation.
- **T257:** admitted a GDT-only, ring-0, 16-bit 80286 protected-mode corpus:
  real-mode `LGDT`/`LMSW`, code/data/stack selector loads, same-CPL far
  transfers, diagnostic `#GP`/`#NP`/`#SS`, and profile-form rejection. It
  deliberately does not claim broad privilege transitions, 32-bit semantics,
  or Windows compatibility.
- **T258:** admitted only a 80386 ring-0 4 KiB paging path: core-owned
  PDE/PTE translation through checked physical memory, A/D updates,
  non-present `#PF` with retained CR2, and narrowed CR0/CR2/CR3 forms. CPL3,
  paging permissions, TLB behavior, TSS I/O, task switching, and general
  32-bit compatibility remain deferred.
- **T259:** admitted a bounded common 80286/80386 16-bit privilege subset:
  CPL3 software `INT` through DPL-permitted gates, `LTR`-loaded 16-bit TSS
  `SS0:SP0` stack switching, paired outer `IRET`, and one observable `#GP`
  gate-delivery route. It excludes generic hardware/IDT delivery, 32-bit
  frames/gates, CPL3 paging, TSS I/O, LDT, and task switching.
- **T260:** admitted a 80386 32-bit-TSS I/O permission map through the
  existing CPL3 path. Allowed and denied byte I/O, truncated multi-byte map
  spans, 80286 no-map behavior, and the `CPL <= IOPL` bypass are covered;
  task switching and all broader TSS semantics remain deferred.
- **T261:** admitted only CPL0 far `JMP` between present GDT 16-bit TSS
  descriptors under both 80286 and 80386 profiles. The core executor saves and
  restores the bounded task state, transitions busy descriptors, and retains
  `#GP`/`#NP`/`#TS` diagnostics on invalid, unavailable, busy, or short TSS
  targets. S5 restores task B's `SREG_STACK` cache classification and locks
  its `#SS` limit path. Task gates, far CALL, nested/IRET task return, LDT,
  32-bit TSS, and switching under paging remain deferred.
- **T262:** admitted an exact-8087 finite `m32real` baseline through the
  existing ESC decoder: owned control/status/tag/TOP state, `FNINIT`, bounded
  load/store and register arithmetic, explicit unsupported outcomes, and
  pending-unmasked-exception `FWAIT -> #MF`. It retains FPU=none ESC
  consumption and makes no 80287/80387, broad IEEE, environment, or
  protected-mode FPU claim.
- **T263:** admitted only the existing 80286 protected-mode `ARPL r/m16,r16`
  form after a corpus proved that its metadata required 80286 but the executor
  incorrectly rejected it below 80386. The core-only corpus covers register
  and ES-prefixed memory destinations, both RPL/ZF outcomes, lower-profile and
  real-mode `#UD`, and rejected-execution atomicity. Other 286/386 instruction
  families remain individually corpus-gated. S4 then aligned the software-
  interrupt contract with the retained real-mode IVT and bounded protected
  16-bit IDT routes, and moved the unrelated descriptor-vocabulary debt from
  an obsolete inline task marker into the TODO ledger; it changes no runtime
  behavior or artifact.

Each completed task's detailed contract, command output, artifact hash, and
provenance remain recoverable from its Git commit. M5 Td S23, Td S27, and Td
S30 retired completed planning records from the working tree so that planning
contains only active work and closure authorities.
