# Research Redistributability

Microsoft binaries are not committed, downloaded, copied, or bundled. Future
BYOB analysis must cover legal acquisition, private local storage, version/hash
matching, user experience, failure handling, and whether the result can remain
outside the default release. No `ntvdm import` command is promised before M10
records a formal Go decision.

Any M10 observation uses owner-provided local inputs read only. Evidence records
only logical component identity, version, architecture, hash, and observations;
it omits local paths and binary contents. A missing or unclassified component is
an unavailable experiment, not a reason to fetch, copy, or substitute a binary.
