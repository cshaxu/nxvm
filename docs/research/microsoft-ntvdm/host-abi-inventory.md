# Host ABI Inventory

Before any implementation proposal, map NTVDM's dependencies on loader,
console, redirection, WOW64, CSRSS, ConHost, registry, services, private entry
points, and version-specific behavior. Every claim needs an evidence record.

The inventory feeds M5 invasive Windows integration research and is an M6 entry
condition. No discovered private ABI becomes a default-runtime dependency.
