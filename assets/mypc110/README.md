# MyPC110 artifacts

This directory contains the fixed DSTN and TFT builds for x86 and x64:
`mypc110_x86.exe`, `mypc110_x64.exe`, `mypc110_tft_x86.exe` and
`mypc110_tft_x64.exe`. Both variants read the adjacent `mypc110.ini` for
runtime media and presentation settings. Deployment does not rewrite the INI
or user-owned CMOS files.

Firmware and font files are validated external build inputs and are embedded
in the corresponding executable. The DSTN firmware is a documented derived
image; raw ROMs and generated byte sources are not stored here. See the
[PC110 qualification proposal](../../docs/nxvm/proposals/m5-pc110-qualification.md)
and [current task state](../../docs/nxvm/states/CURRENT.md) for evidence and
remaining qualification limits.
