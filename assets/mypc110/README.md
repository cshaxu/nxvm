# MyPC110 artifacts

This directory contains `mypc110_x86.exe` and `mypc110_x64.exe`. Both start
with DSTN selected and read the adjacent `mypc110.ini`. While stopped, use
`vdisplay=dstn` or `vdisplay=tft` to select the next cold start. The selection
is not persisted across process launches. Each display has its own CMOS file;
deployment does not rewrite the INI or user-owned CMOS files.

F12 is the virtual PC110 resume button. When the guest has input focus, use
it to wake firmware that has entered its own suspend state. This is separate
from the monitor's `resume` command, which resumes a paused emulator.

Firmware and font files are validated external build inputs and are embedded
in both executables. The DSTN firmware is a documented derived
image; raw ROMs and generated byte sources are not stored here. See the
[PC110 qualification proposal](../../docs/nxvm/proposals/m5-pc110-qualification.md)
and [current task state](../../docs/nxvm/states/CURRENT.md) for evidence and
remaining qualification limits.
