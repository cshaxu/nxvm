# ntvdm64

ntvdm64 is the canonical successor repository for NXVM. It preserves the
bootable whole-machine NXVM product while developing a separately composed,
non-invasive DOS application runtime.

This README is public orientation, not a second architecture, roadmap, or
status authority.

## Start Here

- [Documentation Guide](docs/README.md) is the documentation entry point.
- [Project Goals](docs/design/GOAL.md) state the strategic outcomes.
- [System Architecture](docs/design/ARCHITECTURE.md) and
  [Source Layout](docs/design/CODING.md) define the product and source shape.
- [Product UX](docs/design/UI.md) defines high-level interaction.
- [Roadmap](docs/design/ROADMAP.md) defines milestone outcomes and order.
- [Project Status](docs/states/CURRENT.md) is the only current task and technical
  baseline authority.
